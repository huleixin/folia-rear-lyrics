要求：Node >=24、JDK 21、Android SDK 36/36.1 与相应构建工具，Gradle wrapper 8.14.3。

进入 folia-rear-lyrics/tingyu-android：
1. npm install --ignore-scripts --package-lock=false --no-audit --no-fund
   原始 package-lock.json 有三项传递依赖版本不匹配，npm ci 会失败；本次保留原锁文件，并使用上述安装方式。
2. npx cross-env FOLIA_OFFLINE_BUILD=true npm run cap:sync:android
   此标志关闭构建时的提交名称外站查询；不更改播放器功能。
3. 配置 JAVA_HOME、ANDROID_HOME，或在 android/local.properties 中配置本机 sdk.dir。
4. cd android
5. Linux/macOS: bash gradlew :app:assembleDebug
   Windows: gradlew.bat :app:assembleDebug
