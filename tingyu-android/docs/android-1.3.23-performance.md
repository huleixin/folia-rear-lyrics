# 听屿 Android 1.3.23：播放与页面性能验证

基线：已发布的 1.3.22（04c2e8d）。本轮同时完成上一轮播放迁移/洛雪歌单/返回与弹窗修复，以及最新性能优化。没有迁移歌词舞台到 Compose，没有修改现有歌词编排、Liquid Glass 材质或全局帧率。未连接或操作实体手机。

## 播放与稳定性

- 普通 HTTP、HTTPS、content、file 播放由进程内 Media3 1.11.1 接管解码、音频焦点和耳机断开处理。保留现有歌曲队列、取流、恢复、通知和歌词业务；通过媒体事件适配层连接现有控制器。
- 均衡器/高级音效、自动混音、ReplayGain，以及 Web Blob 音频保留兼容链。在本次会话启用兼容链后不反复交换引擎，避免 Web Audio 重绑与双路发声。没有宣称所有 DSP 都已原生化。
- 原生频谱直接读取播放 PCM；只有正在播放且主舞台可见或背屏醒着时开启 FFT。主屏/背屏均不需要时停止 FFT；既有逐字歌词时钟与背屏发布链保留。未增加麦克风权限。
- 播放/暂停保留短淡入淡出；原生时钟不依赖 UI 每帧通信。阻止旧源事件、重复结束/错误事件和失效播放意图污染当前歌曲。引擎交接只有确认原生输出停止后才启动兼容输出。
- 系统弹窗造成的焦点变化不再清空原生页面或重新发布错误的底栏位置。原生页面保持状态，失焦/后台停止小进度圈及播放指示器的视觉计时；不会全局暂停 WebView 业务。
- 舞台控件使用原生安全区尺寸，忽略隐藏 HTML 的入场 inert 状态。返回历史必须属于本次 App 会话且有应用内前一页；找不到时回应用首页，避免把旧浏览器历史当成退出操作。

## 洛雪与已登录平台歌单

- 选择脚本与选择歌单平台分开：QQ、网易云、酷狗等歌单仍归原账号管理，播放取流使用选中的个人脚本。
- 脚本支持原平台时复用原歌曲标识；需要跨平台时，只接受歌名、歌手、时长相符的版本，一个平台搜索失败会继续检查脚本支持的其他平台。无匹配时显示错误，不偷偷换回原音源。
- 切换脚本会通过既有恢复流程重新获取当前在线歌曲，保留播放位置和暂停意图。本地曲目不受影响。
- 继续复用按脚本/音质隔离的缓存和预取；旧取流请求不能覆盖新选择，缓存写入绑定实际取得地址时的来源，避免把旧音频写进新脚本的缓存。
- 自动化验证使用模拟音源/固定测试数据，不能保证个人第三方脚本或其服务器始终可用。

## 本轮实际性能改动

| 位置 | 改动 | 保留内容 |
|---|---|---|
| Web/Compose 重复控件 | 原生接管时不挂载隐藏的 Web 封面、底栏按钮、进度控件；保留轻量桥接节点及舞台占位尺寸 | 点击、切歌、队列、字幕间距、控制栏自动隐藏 |
| 桥接数据 | 共享未变模型，比较轻量包头；移除额外的整模型/整包 stringify，图片映射按模型复用 | 所有实际数据变化、最新动作回调、会话与版本保护 |
| 原生主线程 | 页面/控件解析、合法性校验、启动缓存序列化移至 Capacitor 工作线程；主线程只接收已准备模型并执行顺序校验 | 原有包大小与字段校验，表单凭据不进启动缓存 |
| GPU 合成 | 移除 Backdrop 外额外强制的整屏 Offscreen；普通设置画布按需使用隔离层 | Kyant Backdrop 采样、折射、模糊、描边不变；有 live 预览挖孔时仍保留必要隔离，歌单封面渐隐遮罩隔离也保留 |
| 设置捕获 | 忽略纯位移/中间淡入帧及无关图片加载；停止整文档重复 JSON 比较 | 布局、颜色、值、禁用状态、可见性边界、表单滚动和 live 预览 |

没有重复修改 1.3.22 已有的舞台 RAF/Pixi 停绘、退出后延迟释放、中文分词 Worker、原生封面缓存、歌单行缓存等机制。

## 验证与可量化收益

- TypeScript 检查通过；播放/取流/页面/返回等 1513 项单测通过，歌词效果相关另 1285 项通过、1 项原有跳过，共 2798 项通过；安卓 JVM 测试 115 项通过。
- 本机浏览器 53 项页面与桥接检查通过，包括冷启动、30 次歌单进出、设置与舞台往返、当前音频播放/暂停/拖动、逐字分词 Worker、预览不连续重建表单、原生接管后隐藏 Web 控件数为零。另 5 项真实 Chrome 音频兼容链检查通过。
- 397 行固定模型、30 次内容未变的父组件重渲染对照：旧方式 30 次额外 stringify，新方式 0 次，避免约 3,051,540 字节的临时 UTF-16 字符串；hook 回归同时确认无新增布局测量和桥接发送。这是受控操作计数，不是 App 总内存/CPU 降幅。
- 显式额外整屏 Offscreen 从 1 层变成 0 层。玻璃材质实现 ChromeMaterial.kt 与基线一致；必要的局部隔离仍存在。实际 GPU 时间收益没有冒充测量值。
- 浏览器原生桥接模拟不等于 Android Media3 解码或 Android GPU 测试。原生编译/JVM 测试通过也不等于已完成真机播放验证。

## 仍需真机验证

1. 小米耳机弹窗、冷启动立即进入舞台、手势返回的合成与动画是否彻底无重影/闪跳；不同系统安全区和液态玻璃取样是否一致。
2. Media3 在真机上的起播、断网恢复、音频焦点/来电/蓝牙、锁屏长时间播放、通知与耳机按键；高级音效/混音与兼容链交接。
3. 背屏逐字歌词同步、锁屏后 LSP 常亮/暂停回系统背屏、两屏同时显示及自动隐藏控制栏。
4. 同设备同歌曲同音量网络条件下分别测普通播放、主屏舞台、背屏、双屏的 CPU、GPU、掉帧、温度和耗电。没有实测前不提供“省电百分比”或“等同原生音乐软件”的承诺。

本机安卓模拟器缺少可用的硬件加速支持，软件模式未成功启动；没有据此声称完成 Android 运行时测试。
