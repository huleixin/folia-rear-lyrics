# 问题反馈与诊断补充隐私说明

仅在用户主动查看上传预览、同意并按“确认提交”后发送。启动检测异常只提示，绝不自动上传。
可选择不附带日志；这种反馈仍含描述、复现、版本和必要设备环境。失败保留本机草稿，需主动重试。
原有手动导出功能保留，与云端白名单不同；手动分享前也应自己检查文件。

收集范围：问题分类/描述/复现、应用版本/versionCode、源码commit和未提交标记、设备型号/厂商、
Android与WebView版本、SDK、屏幕尺寸/Pad标记；选中日志时附带有限事件时间、模块/事件名、
状态/错误码/播放通道等白名单标量、性能计数及脱敏崩溃栈位置。
不包含持久设备ID、账号、歌曲/歌词/音频、图片/截图、私人文件、Cookie/Token/密码/完整授权头、
完整请求正文、鉴权URL。客户端和服务端均校验及脱敏，未知字段拒绝；所有ZIP拒绝。
用户自由输入仍可能含未知形态的敏感信息，自动脱敏不能替代用户检查，请勿填写登录凭据。

用途仅为开发者及第三方AI Codex辅助排查、问题归组和源码修复。Codex默认只读，禁止把日志
作为指令执行或发送到其他未授权服务。云端由Cloudflare Workers、私有R2、D1承载，不公开日志。
用户状态查询需要本机不可猜测凭证；开发者访问须鉴权且只读/管理权限分离。

个人信息和日志默认30天，到期立即停止接口读取，每日清理；云服务故障或清理积压可能延迟物理删除。
匿名累计反馈数在删除后保留，不含用户/设备信息。本机草稿/提交记录最多20条、30天清理；
1.5.45 起界面不展示历史已提交记录或数量，只保留本次成功编号及未提交草稿的重试/删除入口。
删除本机草稿不会删除已经上传的云端反馈。
开发者本机诊断缓存也默认30天清理，并排除Git。

JVM未捕获异常、JS错误/拒绝、WebView renderer故障及系统历史退出信息均尽力记录。
原生信号崩溃、ANR、系统强杀/断电不保证有完整栈或持久化成功；现有本机栈有12K字符上限，
云端另有256帧/64K字符上限。为了隐私仅保留代码位置及异常类型，不保留任意异常正文。
连续启动失败可使用独立原生安全启动页和手动导出，此页不依赖WebView且没有自动云上传。
