# 听屿 1.5.56 播放器调整

基线：1.5.55 / f5e00456，分支 feat/tablet-adaptive。版本：1.5.56 / 271。

- 沉浸播放器展开、收起与共享封面复用经典播放器的 MinimalPlayerMorph / SaltPlayerTimeline；移除独立 bounds/closing 时钟和额外下沉尾动画。整页保持最终尺寸，以绘制裁剪代替逐帧重新测量。
- 收藏回到歌曲信息行、更多按钮左侧；竖屏、手机横屏与平板布局均接入同一收藏业务。
- 竖屏封面按用户参考图缩到原可用宽度的 74%，保持水平居中并补偿尺寸变化后的纵向中心；底部控制区上移 16dp，横屏移除额外向下偏移。
- 底部歌词、歌词舞台、队列三个入口统一圆形承托和图标反馈；删除队列上方独立播放模式徽标。
- 队列顶部播放模式按钮保留原有 48dp / 紧凑24dp尺寸与业务，只替换为听屿 PlaybackModeIcon；当前歌曲定位改为准星图标。
- 关于页的许可证入口进入现有原生设置顶栏右侧，圆圈问号图标及无障碍名称沿用现有许可证导航，移除正文重复入口。
