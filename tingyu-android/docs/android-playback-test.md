# 听屿播放测试版

本包用于对比稳定播放通道与 Media3，定位“所有歌曲不能播放”等问题。名称为「听屿播放测试」，包名 `io.github.huleixin.tingyu.playbacktest`，与正式版同时安装，默认使用稳定内核。正式版 1.3.24 的默认播放行为不变。

## 安装与切换

1. 暂停正式版正在播放的音乐，安装并打开「听屿播放测试」。两版数据分开；测试版需要重新登录音乐平台，或重新导入个人音源。
2. 进入 **设置 → 播放控制 → 启动播放**，向下找到 **播放内核测试**。
3. 默认先用 **稳定内核**。需要比较时选择 **Media3（测试）**，点击 **停止播放并应用选择**。收到原生停止确认后，页面重新载入；请再次进入这里核对 **实际使用**。
4. 每次切换后，先点 **加载 10 秒测试音频**，再返回首页或歌词舞台，用原来的播放按钮试听。加载会替换测试版的当前队列，测试音频不依赖账号、联网音源或洛雪脚本。
5. 两个内核分别测一次提示音，再测试相同的普通平台歌曲、个人洛雪音源歌曲，以及暂停、恢复、拖动进度、切歌、耳机和锁屏播放。

切换不会在播放中热替换内核。停止确认失败或超时会阻止应用选择，请导出日志；必要时彻底退出并重开测试版。选择会保留，自动续播在切换时关闭，以便手动验证。

Media3 测试会关闭测试版的均衡器、自动混音、ReplayGain 和新音频缓存，防止高级音频链或 Blob 缓存让测试走回稳定通道。若本次会话已经启用兼容链，仍可能使用稳定内核，页面会显示实际内核及原因。重新应用 Media3 后先测内置音频；不能只凭选中按钮认定使用了 Media3。

## 导出日志

出现问题后尽快进入同一位置，点击 **导出播放日志**。系统会弹出分享面板，可保存到文件或通过可用应用分享，再把生成的 `.txt` 文件发给开发者。日志在本机保留有限记录，也可重新打开测试版后导出。导出不需要连接电脑或开启 USB 调试。

请同时说明：

- 当时选中的内核，以及页面显示的「实际使用」。
- 内置测试音频能否出声；普通平台、洛雪、本地音乐分别是否正常。
- 是点播放没反应、时间走但没声音、播放一会儿中断，还是直接出现错误。
- 是否使用蓝牙耳机、是否锁屏，以及大概发生时间。

报告包含：选定/实际内核、设备和系统版本、测试版版本、播放状态和音量、原生错误及原因链、有限的 JS 与原生事件记录。音频地址仅保留协议和主机，原始播放链接、私有文件路径、Cookie、授权字段与令牌会脱敏。不会导出个人音源脚本、平台登录数据或完整存储。

## 验证边界

本机浏览器可以验证稳定通道的真实音频解码、进度、暂停/恢复，以及内核选择、原生设置表单、分享导出、原生无响应后的报错与恢复协议。原生单元测试与编译检查可以验证代码与安装包结构。Media3 在特定安卓设备上是否真正出声、蓝牙路由、锁屏续播和实际功耗，仍需手机测试，不能用浏览器的原生桥模拟结果代替。

这是播放诊断包，不作为 LSP/背屏模块升级包。诊断记录也会带来少量额外开销，不建议据此直接得出正式版的功耗结论。

## 构建

在 `tingyu-android` 执行 `npm run build:playback-test`，再在 `android` 目录执行 `gradlew.bat -PtingyuPlaybackTest=true :app:assembleRelease`。测试 Web 资源含专用标记；Gradle 会拒绝把测试资源与普通应用身份混用。

普通发行从 1.3.25 起默认启用系统原生播放（`BuildConfig.NATIVE_PLAYBACK`）；构建纯 WebView 版本时设置 `TINGYU_NATIVE_PLAYBACK=false`。正式包不包含测试资源，Gradle 会拒绝测试资源与普通应用身份混用。

## 正式启用

1.3.25 起原生播放为默认通道：`PlaybackSpectrumProcessor` 忽略空输入，原生失败会在本次会话锁回兼容通道，设置页提供手动切换。诊断版与正式版共用同一存储键 `tingyu_playback_test_engine_v1`，正式版默认 `media3`，诊断版默认 `web`。

## 第二版测试包：空缓冲区故障修复

1.3.24-playback-test.2 可直接覆盖安装第一版测试包。正式版版本号及默认内核保持不变。

第一版的频谱处理器没有处理 Media3 管线主动传入的共享空缓冲区，会发生 `The source buffer is this buffer` 异常；普通输入后再收到空输入还可能覆盖尚未读取的输出。本版直接跳过空输入，保留正常音频和频谱处理。已用项目实际依赖的 Media3 1.11.1 处理器及完整音频管线测试，覆盖空轮询、PCM 输出内容、单/双声道格式切换与结束排空。

同时修复：准备阶段失败后重试仍失败时，旧错误导致新播放请求迟迟不结束；重复错误通知不能让元素重新变为未暂停状态；真正的播放等待超时会暂停并取消播放意图。成功重试则会清除上一次错误。没有更改普通稳定播放通道或歌词视觉。

请重新选择 Media3 并应用，加载内置 10 秒测试音频后用原播放控件试听。正常后再测试平台和个人音源歌曲。失败时仍用相同入口导出日志。
