# 听屿 Android 1.3.39

针对用户截图中歌单详情上方灰绿色封面背景与下方深色背景之间的横向接缝，修改原生歌单背景的收尾方式。保留 1.3.38 的音质规格标签、歌曲布局、当前歌曲高亮、定位、播放控制和既有玻璃效果。

## 处理

- 旧封面层在有限高度的边界处才完成线性透明衰减，并依赖显式 Offscreen + DstIn 混合蒙版。代码路径中存在清晰的图层结束边界；截图可确认视觉接缝，但不能单凭截图确定具体 GPU 混合指令的执行结果。
- 封面模糊仍为 22 dp、透明度仍为 0.28、尺寸和位置保持原值。去掉封面容器显式离屏混合蒙版，改为普通 SrcOver 渐变覆盖，使封面逐渐融入底下的原页面颜色。
- 使用两端斜率归零的平滑曲线，在封面层高度的 90% 处完成衰减，最后 10% 为与页面一致的不透明过渡尾段，避免把未完成的过渡直接裁切。
- 覆盖颜色按整页坐标采样原三段背景渐变，包含原中间色的位置；不是在末端盖一块固定黑色。原三种颜色保持 `#03221A`、`#03130E`、`#031812`。
- 渐变只绘制在封面背景容器内，不遮罩文字、歌曲或控件。停止点在 drawWithCache 中按布局尺寸构建，不逐帧计算，不增加整屏 GPU 图层；没有调整全局帧率，也没有关闭 Liquid Glass 或歌词特效。

## 验证与边界

- 172 项 Android JVM 测试通过，本轮新增 6 项，覆盖原调色不变、渐隐端点/斜率、单调性、不同高度下尾段颜色与全页渐变一致、背景中间色衔接及无效尺寸保护。
- 本轮只修改 Android Compose 背景，未修改 Web 歌单 CSS、数据源、缓存、Media3、通知栏、歌词舞台或背屏路径。浏览器截图不能验证这条 Android 绘制链路，因此不把上版浏览器检查作为本轮接缝修复证据。
- Android 发布构建、必要 lintVital、APK v2/v3 正式签名和版本信息校验通过，versionCode 为 63，包名与原发布证书保持一致；原生播放启用，图形诊断和播放测试开关关闭。全量 Lint 的既有问题未扩展处理，不把必要 lintVital 通过等同于全量 Lint 通过。
- 未连接手机，未做 GPU/功耗测量。显式蒙版已移除，但用户手机上的实际衔接效果、玻璃采样及滚动时表现仍需复测，不能据单元测试声称已实机验证。

安装后用原截图的歌单检查第三至第五首附近，以及上下滚动后的背景过渡；同时确认音质标签、定位按钮与底部小播放器保持正常。
