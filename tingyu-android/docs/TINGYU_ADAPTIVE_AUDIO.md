# 听屿 1.3.20-beta.1：多尺寸布局与音频工具

## 布局

以应用实际可用的 CSS 视口判断布局，840px 及以上使用侧栏，宽屏且高度不超过 600px 使用车机布局。旋转或进入分屏时不重建播放器。普通 Android 车机直接运行 APK；此版没有接入 Android Auto/AAOS 车载服务。

## 本地文件夹

资料库 → 本地 → 文件夹。扫描系统音乐库后按存储卷和真实相对目录分类，可逐层进入、搜索排序文件夹、查看本目录或包含子目录的歌曲，再使用原有歌曲列表播放及加入队列。返回键先返回上级文件夹。

已有系统扫描记录需要重新扫描一次补齐目录；保留原歌曲 ID、手动歌词选择、封面和关联资料。没有原始目录信息的旧文件导入记录继续留在原分组，重新导入原文件夹后才能取得可靠目录。系统不允许访问的目录不能由播放器推断。扫描不删除未连接存储设备的旧记录。

文件夹导入通过系统授权，复制的文件仍保存在应用私有目录，原文件夹路径仅用于展示分类。授权目录的枚举和复制均在后台执行。

## 音质和音效

小播放器的音质标签、主屏歌词舞台底部的音质按钮均可打开音质面板，也能从该面板进入独立音效调节器。在线切换先取得地址并检查音频元数据，再保留当前进度替换音频；失败保留原音频。首选音质与当前已确认音质分别显示；缓存或旧预取未提供确切音质时标注未确认。本地音乐按原文件播放，展示已读取的格式和码率。

均衡器复用现有十段与音效链，滑动时预览，释放/关闭时保存。关闭处理时继续使用现有旁路，不创建第二个播放器。

## 洛雪自定义源（首版）

设置 → 集成，或音质面板 → 洛雪自定义音源，导入 UTF-8 `.js` 文件。先检查初始化和声明能力，再手动启用；可随时切回原音源或删除脚本。检查成功代表协议初始化成功，实际取流需播放对应平台的歌曲验证。

现有网易云、QQ、酷狗仍负责搜索、歌单与歌曲身份，自定义源仅负责 `musicUrl`。脚本声明酷我、咪咕不代表此版增加了这两个平台的搜索目录。不内置或分发第三方源。

实现 LX 事件、请求回调、超时/取消、定时器、Buffer 常用编码、MD5、随机字节及常用 AES 模式；此版不支持 RSA、zlib、multipart、Node.js 模块加载等扩展。依赖这些接口的脚本需要后续适配，不能承诺所有 LX 脚本兼容。

脚本在按需创建的 Worker/QuickJS WASM 中执行，不能访问应用 DOM、IndexedDB 或原生桥；内存、执行时长、消息数、并发请求均有上限。停用或换源会终止旧实例，空闲 30 秒释放运行时。音频缓存和预取按源区分，避免切换后误用其他源的旧地址。Android 通过原生 HTTP 请求接口绕过浏览器跨域限制；浏览器预览仍受目标网站 CORS 限制。

## 验证范围

自动化覆盖手机、平板与宽短屏布局、洛雪脚本初始化/取流/停用、文件夹层级返回、音效入口以及音质失败/过期请求保护。没有连接设备时，浏览器和构建测试不能证明实机功耗、车机硬件解码表现或所有第三方源的可用性。
