# 听屿 Android 1.3.13：商籁背屏歌词避让

版本1.3.13；Android versionCode 26；包名io.github.huleixin.tingyu。

## 修复

- 以解析器的原歌词行为单位聚合当前主歌词，不只按镜头追踪的英雄词定位；在词组排版、逐字运动、相机追踪和段落转场之后等比调整整句，避开摄像头与屏幕边缘。
- 排版宽度使用背屏右侧安全宽度；核心文字、色差副本、字旁引导线、装饰框与附着图形使用一致变换。背景MG、几何、巨型装饰字、回声继续使用整屏，没有右侧矩形裁切。
- 入场/离场各0.5秒平滑交接，每帧先恢复原始姿态，避免修正累计。保留原有7种版式、逐字时序和跟随运镜。
- 开启后期镜头畸变/色散时，按实际着色器的采样映射预留空间；横向撕裂转场按纹理池分辨率和当帧强度预留位移，防止后期处理再次把主字推出安全区。
- 翻译/音译出现时同步更新画面，修复两帧预留位置延迟。自动隐藏的播放控件不占固定布局空间。
- 背屏尺寸变化后维持canvas的100% CSS宽高，避免像素密度取整导致画布尺寸偏差；主屏不启用背屏避让。
