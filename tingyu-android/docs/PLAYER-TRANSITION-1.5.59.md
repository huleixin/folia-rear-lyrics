# 听屿 1.5.59 双播放器跟手转场与拖影修正

基线：1.5.58 / 708fd37c4de48f6865f47cb0bd6728f4a7b71d54。版本：1.5.59 / 274。

## 改动

- 经典极简与沉浸极简改用同一份可逆的 0–1 展开进度。迷你栏上滑、全屏顶部下拉、封面空白区域下拉及经典歌词页顶部继续下拉，都能逐帧跟手；停住、反向拖回、松手落定与取消回弹保持连续。
- 经典歌词列表先处理自身滚动；滚到顶部后，继续向下移动才交给播放器。播放器接管后，反向拖动立即回拉外壳，歌词列表不再同时滚动。
- 点击展开与收起仍使用同一进度和现有弹簧；自动动画未结束时可以重新抓住，回拖超过落点会取消原收起。
- 经典封面的横向切歌继续由原有封面手势处理，纵向拖拽只在横向方向未锁定时进入展开/收起。
- 修正沉浸转场时裁剪形状延迟一帧造成的拖影：圆角与裁剪边界现在读取当前帧快照，并在手指移动时触发图层更新。转场期间场景与移动封面进入同一个当帧离屏目标，结束后立即恢复普通合成。
- 沉浸背景的动态负载提示原先没有任何路径设为开启，转场期间仍按正常速度刷新。现在展开、收起、歌词页切换和转屏都会触发降载分支，背景颜色和相位保持连续。
- 经典顶部收起、收藏与舞台按钮重新接入标题栏显隐进度，跟随同一外壳一起出现和退场。
- 顶部收起按钮及沉浸标题栏在原生安全区为 0、Compose 状态栏窗口边距已被消费时，回退到真实窗口状态栏高度；两者都存在时取较大值，避免重复留白。

两套播放器仍共享听屿现有播放服务、队列、歌词与音源状态。未修改播放核心、音源导入、歌词舞台、Vulkan 舞台、背屏 AOD、全局主题或底部导航。
