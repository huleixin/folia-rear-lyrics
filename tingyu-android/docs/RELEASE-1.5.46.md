# 听屿 1.5.46

- 新增边听边存：完整音频缓存后优先从本地播放，支持应用重启后继续使用。
- 新增歌单音频缓存：查看进度、重试失败任务、停止任务，并可选择仅 Wi-Fi 自动缓存及空间上限。
- 完善洛雪备用音源：支持平台原音源优先、多个已启用脚本依次尝试，并核对跨平台歌曲版本。
- 加强缓存完整性检查；不完整或校验失败的音频不会计入可用缓存，播放失败时重新尝试音源。

versionName 1.5.46，versionCode 261。沿用原 Release 签名和正式包名 `io.github.huleixin.tingyu`，可覆盖升级原正式版。独立测试版数据不会自动迁入。

使用：设置 → 存储 → 离线音频缓存，开启「边听边存」；歌单内点击「缓存歌单」。功能默认关闭，仅 Wi-Fi 默认开启。

仅缓存音源实际提供的完整、未加密音频。未保存的歌单页面、封面、歌词仍可能需要联网。后台下载已入队的歌曲，后续歌单分页需回到应用继续发现。

已完成本机自动测试及正式包校验；真实设备覆盖升级、断网重启、网络切换、锁屏后台及功耗仍需设备验证。详见 [功能说明](offline-audio-cache.md) 和 [先前测试包报告](offline-audio-cache-test-report.md)。
