# 听屿 1.5.60 退出转场修正

基线：1.5.59 / 52b9bf06dbef9bfee1e2769e4547589895cc866b。版本：1.5.60 / 275。

## 改动

- 沉浸歌词页退出时，歌词场景随外壳按同一进度向下移动。此前场景固定在整屏位置，拖动时只是在被裁切并淡出，看起来像没有跟手。
- 退出前半段保持外壳与歌词不透明，仅在接近迷你栏终点时完成收口。提前整页淡出会让歌词看起来先静止再突然消失。
- 移除经典与沉浸外壳的整屏离屏合成。慢速拖动时，全屏缓冲会保留上一帧的裁剪和背景像素，形成白色横带与左侧残影。背景、场景与移动封面现在各自更新自己的绘制层。
- 经典外壳进入转场时由移动层统一承载位置变化，不再只移动裁切区域。
- 经典点击收起时从完整展开状态开始；到达迷你栏终点后直接卸载页面，不再追加第二段滑出和淡出。
- 迷你栏在拖动末段才进入，保持在移动外壳下方，避免与正在退出的歌词重叠。
- 沉浸歌词在转场期间继续绘制；自动跟随滚动仍由现有转场状态暂停，避免在拖动中抢占手势。
