# 听屿 Android 1.3.27：音源导入与汽水登录恢复

## 修复

- 洛雪导入从 HTML 文件输入框改为明确的导入按钮。安卓直接调用 FoliaNative 的 Storage Access Framework 文件选择器，不依赖 Compose 转发点击后的浏览器用户激活；浏览器保留普通选文件回退。
- 仅读取用户选中的 `.js` 文件，在独立线程限量读取 UTF-8（最大 1 MB）；取消、格式错误、读取失败和脚本初始化结果都有反馈，不申请整个存储空间的访问权限。
- 音源管理沿用现有弹窗和界面的浅绿/深绿配色、紧凑字体及按钮；音源列表改成卡片，平台和音质分组，详细介绍默认折叠，手机和平板都保留滚动及返回行为。
- 汽水原本已将凭据保存在本地，但票据在 access code 之前失效时，登录状态检查会直接清除账号。本次先使用已有授权续取票据，再验证账号；明确拒绝恢复后的凭据才清除。
- 续期会轮换 access code 和票据。原实现等到最后的账号检查成功才落盘，中途断网可能使旧凭据留在磁盘。本次分阶段保存新凭据，重启后可以继续恢复；并保留请求代次检查，退出登录后旧请求不能恢复账号。

## 验证

- 新的七项汽水持久会话测试覆盖冷启动、票据提前失效、续期中断、普通断网、明确撤销和并发退出。旧代码三项失败，修复后全部通过。
- 汽水协议、导入服务及相关音源切换共 37 项 JS 测试通过；TypeScript 检查通过。
- 124 项 Android JVM 测试及发行构建通过，包含原生文档的 UTF-8、精确大小边界和不可读取情况。
- 浏览器使用真实弹窗与脚本 Worker，通过模拟原生端口验证导入、启用、取消、错误反馈、从 Compose 设置文档转发点击及返回。手机/平板、浅色/深色共 20 项检查通过，未出现未捕获错误。
- 未连接手机，未使用真实汽水账号。系统文件选择器的设备表现以及真实账号经过长时间后续期仍需设备验收；服务端实际撤销的授权仍需重新登录，不会伪装成已登录。

版本 1.3.27，versionCode 51，沿用原有发布证书。
