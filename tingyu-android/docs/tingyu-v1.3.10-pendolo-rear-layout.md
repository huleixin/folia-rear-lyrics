# 听屿 Android 1.3.10：时计背屏齿轮与歌词适配

版本 1.3.10 / versionCode 23，沿用原包名和发布签名，可覆盖安装。

## 修复

此前时计齿轮沿用主屏的左边缘圆心，大半齿轮超出物理屏幕；只调整歌词无法解决机械装饰被截断的问题。

- 背屏统一计算齿轮、导向环、中心渐变和歌词圆弧的位置。圆心靠近摄像头安全区左边界，完整机械组件保留在物理屏幕内。左半圈允许进入摄像头区域，右半圈位于安全区。
- 齿轮尺寸按完整装饰范围等比限制，包含最外层导向环和渐变留白。位置、尺寸不会随当前歌词长度变化。
- 当前歌词锚定在齿轮右侧，按实际文本、翻译和音译的换行高度适配字号，并为合唱强调预留空间。当前歌词不再随切句弹簧暂时转入摄像头区域；齿轮棘轮和周围歌词保留原有动画。
- 背景继续铺满整屏。安全区边界没有新增裁切容器；上下文歌词可在整屏范围运动。底部播放控件不占用永久歌词空间。
- 修复背屏透明歌词轨道拦截播放按钮点击：背屏触摸交给宿主页面处理，主屏歌词交互保持原有行为。
- 抽取共享歌词绘制组件；适配仅作用于时计背屏，不更改其他已验收样式。文本测量在歌词、字体或尺寸变化时执行，不增加逐帧 React 更新或测量循环。
