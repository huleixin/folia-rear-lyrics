# 听屿 Android 1.3.7：回环轴线对齐与闪动修复

版本 1.3.7 / versionCode 20，沿用原包名和发布签名，可覆盖安装。

## 修复

- 回环轴线移到摄像头右侧，与文字轨道共用一个固定中点。347×212 CSS 背屏的中点为约 (222.74, 106)，即横向约 64.2% 处，对应反馈图红线的大致位置。底部自动隐藏控件不占用永久排版空间。
- 轴线音量响应保持原中点；按旋转角度限制最大长度，避免放大时再次跨入摄像头区域。
- 取消 1.3.6 按每帧可见字边界重新平移、缩放整句的做法。可见字集合会随透明度阈值改变，容易引入位置和大小突变。改为布局时预先计算覆盖整个椭圆轨道、最强节拍及旋转字形的固定范围，播放过程中不因淡入淡出改变重心或基础缩放。
- 待唱句成为当前句时，前后两套 word offset 可能相差很大。新增 240 毫秒连续交接，复用现有时钟与轨道订阅，不增加动画循环；跨多句跳转仍可立即定位。
- 保留回环曲线、逐字高亮、景深和节拍响应；背景继续整屏，不添加右侧裁切框。正面舞台、原生同步、摄像头几何及已确认正常的其他样式未修改。
- 自然字形尺寸只在布局变化时读取；高频路径没有 React state 更新，也不逐帧读取 DOM 尺寸。移除了上一版逐帧整句拟合和临时字形数组。

## 验证

- TypeScript 通过；113 个 visualizer 测试文件通过，1252 项通过，1 项既有跳过。
- 轨道单测扫过 0°/45°/90°、三种强度、三档音量、72 个轨道相位及旋转字形四角；另测轴线端点与切句连续性。
- Chrome + Playwright：329×208、347×212、393×249，normal/chaotic、0/1 两档音量、中文与长英文、每句五个播放阶段，180 个正文及轴线边界采样均通过；连续切句另测 24 点，无正文缺失和越界。
- 连续播放：normal 无音量、normal 最大音量、chaotic 最大音量三组，共 2160 帧，涵盖播放与切句。无正文空白帧、无检测阈值内的异常位置/大小跳变，轴线中点始终固定。切句修正前曾记录最大单帧位移约 94.69 CSS 像素，修正后三组最大值约为 2.80、3.66、4.08 CSS 像素。该数据来自浏览器验证，不是真机帧率或功耗指标。
- 实际双文档背屏页面：完整 347×212 iframe；暂停、继续、下一首、控件自动隐藏及唤回正常，无页面异常；另检查正面舞台预览。
- Android assembleRelease / testReleaseUnitTest 成功，34 项原生测试通过；包名、1.3.7 / 20 版本元数据和原发布签名验证通过。

本轮无 Android 真机连接；预览图和录屏来自浏览器，最终实机轴线位置及闪动是否完全消失仍需安装后确认。
