# 听屿 v1.3.125：封面恢复、柔光与进度光尾

基于 v1.3.124（f85411fc），versionCode 从 147 增至 148。

## 修改结果与源码证据

### 封面

- 旧 MinimalArtwork 在加载失败时只有空处理；URL 有值时连占位内容也没有。现在由 useMinimalArtwork 管理有界的加载与恢复。
- 主封面使用确定的正方形容器，内部图片绝对填充；避免百分比高度依赖自动高度容器。
- 先尝试显示地址，再读取当前歌曲已有缓存，再尝试当前歌曲原始封面，最后最多重试显示地址一次。同地址的原图不重复尝试。
- 单轮最多 4 次图片加载，每次最多 4.5 秒；缓存读取最多等待 2 秒。超时终止该图片请求，不持续轮询。
- 以现有 songKey 隔离结果；切歌后旧回调不能提交。不是用上一首的封面冒充恢复。
- 保留最近 16 个已解码 URL 状态。自行恢复的 Blob URL 由该组件释放，不撤销播放器传入的共享地址。
- 完全失败时显示有尺寸的封面占位，不再留大片空白；下次重新进入仍可重新尝试。
- 歌曲原始身份由已有展示快照传入，保留 Automix 的画面交接语义。

这些是已确认的显示与恢复缺陷。用户真机偶发丢图是否还涉及 WebView GPU 合成，需要继续实机确认，不能仅凭测试宣称百分百消失。

### 背景接缝与流光

- 原光层仅与屏幕同大，但会平移，矩形边界可能进入可见区域。现在四边扩大 20%，覆盖最大位移，仍由原视口裁剪。
- 另一个实际问题：minimalPalette 输出 `rgb(57 31 84)`，共享颜色读取只识别逗号格式，因此原先柔光的提亮函数未执行。扩展现有 colorMix，正确识别空格、斜线 alpha 和百分比 RGB，并补测试。
- 三层柔光采用 10/12/14 秒单程周期，增强封面色彩与位移；浅色单独降低叠加强度。
- 不引入背景 Canvas、FFT、粒子、实时模糊或 JS 动画循环；依然仅移动已绘制的 CSS 色彩层。
- 暂停、页面隐藏、舞台覆盖及减少动态效果时停止动画。没有修改 LSP、Shizuku 或 AOD。

### 进度光尾

- 直接沿用 ProgressBar 原有 MotionValue 与拖动位置，不另建进度时钟、播放器查询或 RAF。
- 在既有滑块载体上发布进度比例，极简页用其绘制最多 76px 的渐隐光尾，短进度时限制尾长，避免伸出进度条左端。
- 播放时柔和明暗变化，拖动时短暂增强；暂停、后台或页面被舞台覆盖后停止动画和不必要的进度 DOM 更新。
- 样式限定在极简页，不给其他进度条增加光效；共享进度拖动与无障碍结构保留。

### 播放按钮

- 旧可用性只看 JS audioSrc 或独立歌词会话，没有读取有效的 Media3 输出租约。
- UI 现在读取原有 output identity，核对 sessionId、songKey、epoch、媒体就绪状态与错误；有效当前歌曲可控制时不因 JS 地址未同步而禁用。
- 旧歌曲、失效租约、空 epoch 和原本不可控制的会话仍不能启用按钮。
- 原生确实处于网络准备且元数据未就绪时，提供独立准备信号；按钮显示加载图标和无障碍加载标签。可正常暂停的缓冲会话仍保留暂停操作。
- 这是只读展示判断，没有更改播放命令、原生/兼容交接、播放队列或歌词权威时钟，也没有新增轮询。

## 验证

- TypeScript 通过。
- 15 个相关前端测试文件，94 项通过。包括新增的图片失败/缓存/原图恢复、超时、过期回调、StrictMode、原生当前/旧歌曲租约、准备状态与 RGB 解析测试；保留 AOD、导航和歌词回归。
- Android JVM：922 项通过。
- 浏览器：极简原回归 35 项、舞台转场 29 项、前版外观与歌手 23 项、本版专项 20 项，共 107 项通过。
- Browser plugin not available，使用现有 Playwright 和真实组件预览；播放与网络故障为可控模拟，不是手机或线上音源实测。
- 本版专项在深浅主题下，采样 0/2/5/8/12/20/28 秒动画位置，三个光层的四边始终覆盖视口。
- 对背景截图比较 0 与 8 秒时间点，平均 RGB 通道差：深色 18.89，浅色 9.25（0–255）。这是颜色变化证据，不是屏幕帧率或功耗测量。
- 验证了进度条拖动、光尾范围、暂停停动、系统减少动态效果、封面原图恢复与全部失败占位。
- 构建沿用原签名配置，发布前校验既有证书；APK 的实际 SHA-256 见 GitHub Release。

## 手机重点验收

1. 冷启动进入极简页、快速切歌、连续播放后进出播放器：封面不塌陷、不错误沿用上一首。
2. 断网、恢复联网、缓存封面失效：成功恢复或者明确占位，无无限重试。
3. 深浅模式观察右侧边缘及完整流光周期，没有矩形接缝；确认增强后的亮度和运动观感。
4. Media3 已播放时立即进入：暂停按钮应可用；真正准备时应有加载反馈。
5. 拖动进度、暂停、后台恢复：光尾跟随真实进度，停止播放后不继续闪动。
6. 前版舞台上下转场、歌手入口、背屏卡片、AOD 和 Shizuku 保持原行为。

本轮无连接真机，不宣称已测屏幕 FPS、GPU 内存、功耗或所有偶发故障已经消除。
