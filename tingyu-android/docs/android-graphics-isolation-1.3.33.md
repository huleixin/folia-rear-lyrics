# 歌词闪烁对照测试（1.3.33-graphics-test.1）

**当前状态：闪烁根因未定位。** 这个包提供受控隔离实验，不是“歌词闪烁已修复”的版本。未连接手机，没有执行小米 17 Pro GPU 验证，也没有实测历史 1.3.31/1.3.32 APK 的差异。

## 安装及入口

- 使用与正式版相同的包名、签名及版本代码 57，名称带 `graphics-test.1`。覆盖安装保留账户和歌单；测试后可重新安装 1.3.33 正式 APK。不要卸载清除数据。
- 入口：设置 → 播放控制/播放设置 → 播放引擎区域下方 → **歌词闪烁 · 对照诊断**。
- 原生引擎、音源、音质、样式、背景、歌词以及播放位置在各组保持相同。切换实验会暂停播放并重启界面，不自动更换播放引擎或音效设置。

## 实验条件

| 组别 | 唯一变化 | 其他图形条件 |
|---|---|---|
| A | 基线，保留 1.3.32 的完整采样及 `.999` 策略 | WebView 原层策略不变 |
| B | 仅歌词舞台路由不参与玻璃背景采样 | `.999` 及 WebView 层策略不变；保留全部歌词特效，玻璃控件仍存在 |
| C1 / C31 | 仅移除 `.999` 的 Compose 隔离层 | 继续玻璃采样，WebView 原层策略不变；对应 1.3.31 的这条渲染策略 |
| C2 / C_HW | 仅设置 WebView 硬件层 | 继续玻璃采样及 `.999`；额外层只用于本组诊断 |

代码核对确认：1.3.31 到 1.3.32 新增了 `.graphicsLayer { alpha=.999f }`。TextureView 案例不足以证明它能修复 WebView。C1/A 比较的是**本测试包内相同条件下的渲染策略**，不能当作已经实测两个历史 APK。

B 的采样隔离只在歌词舞台生效；此时原生内容页已经移出舞台，采样源为 WebView。离开舞台的原生页面继续原采样路径。不得将 B 直接作为正式版删除 Liquid Glass 的方案。

## 推荐顺序

1. 安装测试包，进入上述入口，确认当前为 A。选择同一首歌及样式，预热播放约 10 秒，避免把第一次加载差异混入比较。
2. 点击“开始记录（90 秒）”，返回舞台，播放或拖到目标时间段。优先使用录屏中的 **《茶花开了》王睿卓、云阶、原银灰背景、约 00:52–00:56**，随后检查流光、星象。不要换组时同时换歌、背景或音质。
3. 录屏时观察顶部固定 W 与 N。发生闪烁时点击任一个“记闪烁”。W 在 WebView 内且不参与歌词动画；N 是独立的 Compose 原生标记。
4. 回到诊断入口，选择本组观察结果，停止并保存。切换到 B 后界面重启，重新选择同样的条件，再记录一组。
5. 恢复 A，再切 C1；必要时再恢复 A，切 C2。设置及原生验证均禁止 B 直接切到 C1/C2，防止同时改变两个变量。每一组重启、预热后再比较。
6. 点击“导出全部对照日志”，将日志和录屏一起提供。最多保留最近八组，每组最多 180 条记录。采样默认每秒一次，最多 90 秒，仅前台舞台读取绘制状态；标记可补充现场快照。

## 如何解读

- 只有歌词消失而 W/N 均稳定：优先检查歌词元素、Canvas/WebGL 局部图层及逐字状态；仅凭标记不能进一步区分文字 DOM 和子 GPU 图层。
- W 与歌词同时消失而 N 正常：优先检查整个 WebView 画面/录制/采样路径。
- N 也异常：进一步检查 Compose/窗口合成及系统 GPU，不能直接归咎 React。
- 日志出现 `react-unmount` / `shell-unmount`、实例编号变化，或容器 `display:none` / `visibility:hidden` / `opacity:0`：可以指向组件生命周期或隐藏逻辑。
- 比较组别是否改变现象需要真实手机录屏；程序不会根据采样自动宣布根因。

## 诊断范围及成本

- 记录原生路由、WebView 可见性、附着/分离、尺寸、硬件层类型、公开 OnDraw 计数、Compose 根组合及逻辑隔离层的生命周期。
- 记录 React renderer/shell 挂载、容器状态、歌词/播放时钟、当前行和有限逐字阶段/透明度。Canvas 不做像素回读，也不创建额外 WebGL 上下文。
- 公开 View/Compose 计数**无法证明底层 GPU 纹理是否真的重建**；如果所有标记和状态均正常，仍需真机 Perfetto/GPU 跟踪。不能用浏览器测试替代。
- 没有逐帧 React 更新、MutationObserver、截图回读或长期后台采样。保存仅发生在停止/导出/切组；记录本身仍有少量测试开销。C2 的额外硬件层可能增加 GPU/显存负担，只用于验证。
- 正式 1.3.33 APK 不含本轮图形行为改变、标记或采样；后续普通构建 `GRAPHICS_DIAGNOSTICS=false` 时不安装诊断监听器，也不执行这些实验。
- 截至交付：未排除任何需要真机 GPU 验证的闪烁原因；哪组改变现象、最终根因及长期修复的 GPU/电池收益均待设备结果。
