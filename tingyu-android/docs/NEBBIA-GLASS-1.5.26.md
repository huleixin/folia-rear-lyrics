# 1.5.26 / 241：恢复雾笺擦雾字迹

2026-11-13，针对用户反馈的背屏灰白实心字迹。

原因：1.5.25 在 nebbiaShaders.ts 额外将字迹遮罩混合到固定深色/浅色 ink，并在透明模式提高 alpha。这改变了擦雾透出窗外的原有材质，部分水痕也被染成实心浅色。

修改：删除这段新增颜色/不透明度覆盖。继续使用原有 scene 采样、薄水膜与边缘湿润效果，以及透明模式的原有 alpha 计算。保留 1.5.25 的背屏水滴尺寸缩小、减弱折射/高光、字迹处减少透镜覆盖和收紧擦痕边缘。未新增颜色替代方案。

验证：

- Vitest：32 项通过（雾笺、背屏参数和 Android 页面归属）。
- Playwright：背屏 WebGL 的 DPR 1/3 两项通过，包括长句、Seek、字号、相机安全区与页面异常检查；实际渲染截图已查看，固定浅色填充已消失。Browser plugin not available，复用既有 Playwright。
- 资源同步、Android Release 构建与签名校验作为发布包验收项目。
- 无连接手机，实际背屏材质、动态水痕和灯光下可读性仍需覆盖安装后确认；不宣称真机测试通过。

变更文件仅 nebbiaShaders.ts、package.json、package-lock.json 及本记录。版本递增方便区分安装包。
