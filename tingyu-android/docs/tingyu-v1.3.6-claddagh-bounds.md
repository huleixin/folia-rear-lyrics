# 听屿 Android 1.3.6：回环背屏避让修复

版本 1.3.6 / versionCode 19，沿用原包名和发布签名，可覆盖安装。

## 修复内容

回环的椭圆轨道原本以整块背屏的中心为原点，歌词斜向展开、强调放大后会进入左侧摄像头区域。

- 背屏歌词轨道的阅读重心改为摄像头右侧；当前句按每个字素的旋转、字号和动态放大计算最终包围盒，必要时整句等比适配，不压扁文字、不用裁切掩盖越界。
- 保留椭圆回环、逐字高亮、景深虚化和音量响应。当前句退场时逐渐释放适配，后续动画仍可以进入整块背屏区域。
- 背景和轴线继续全屏；不为自动隐藏的控件永久预留底部空间。
- 初次进入时直接采用真实背屏尺寸，避免用桌面默认尺寸初始化轨道。
- 复用已有摄像头安全区和整句拟合工具；自然字形尺寸只在布局变化时读取，边界计算复用现有绘制循环，没有增加逐帧 DOM 尺寸读取或 React state 更新。
- 仅调整回环的背屏排版，正面保留原有路径；已确认的浮名、花火、群唱、心象和云阶实现及共享几何工具未修改。
