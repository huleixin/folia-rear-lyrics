# 听屿 Android 1.3.9：补齐莫奈背屏音波避让

版本 1.3.9 / versionCode 22，沿用原包名和发布签名，可覆盖安装。

## 修复

上一版只适配了莫奈歌词栏，底部音频可视化仍从整屏左侧绘制。现将音波容器改为使用与歌词相同的摄像头安全区：左边界、可用宽度和底部边距全部来自既有安全区，不再固定在 left: 0。

- 柱状和曲线两种音波均在摄像头右侧完整显示；保留原有 40 像素高度、Canvas 绘制和音频响应。
- 在安全区内添加少量水平留白，并按既有屏幕边距上移底边，避免贴着圆角边缘。
- 改动仅涉及背屏音波容器的位置和宽度；歌词排版、整屏背景、主屏音波和音频采集逻辑保持原有行为。
- 不新增动画循环、逐帧 React 更新或布局测量。开发预览补充了音波样式和非零频谱输入，便于覆盖两种模式的强弱响应。

## 验证

- TypeScript 通过。
- Chrome + Playwright：329×208、347×212、393×249 三种尺寸，柱状/曲线、零输入/255 模拟频谱输入，共 12 组检查。实际 Canvas 及当前歌词均在安全区内，无页面异常。
- 检查实际绘制像素：零输入的可见音波高度约为 1.5–2 CSS 像素，强输入约为 30.5–32 CSS 像素，六组强弱响应比较均通过。
- 实际双文档背屏页面联调：347×212 iframe；音波 Canvas 位于约 x=108.44、y=166.80，宽约 228.59、高 40，处于摄像头右侧；暂停、继续、下一首及控件自动隐藏/唤回正常。
- Android assembleRelease / testReleaseUnitTest 成功，34 项原生测试通过；包名、1.3.9 / 22 版本元数据与原发布签名验证通过。

本轮无 Android 真机连接；预览和音波响应数据来自浏览器模拟输入，最终实机效果需安装后确认。
