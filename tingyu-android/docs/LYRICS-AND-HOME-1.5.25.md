# 1.5.25 / 240：背屏隔离、雾笺与桌面歌词

2026-11-13。用户确认的五项修改，最终按钮位置按补充要求改为右上角横排小图标。

## 问题与实现

1. Shizuku 日志记录了 Display 0 暂存、迁移 Display 1 的路径，且存在迁移成功记录。原代码在非目标屏时先暂停 WebView 并返回，未必隐藏已绘制画面，是正屏残留的代码风险；日志本身没有完整捕获用户看到正屏的那一帧，不能宣称已真机复现。
   - RearLyricsActivity：隐藏操作置于暂停分支之前；绘制前观察实际显示屏变更，清除错误屏幕上的不透明背景；相机恢复同样校验目标屏。
   - RearInteractionFrame：每次 draw 校验显示屏与 session，暂存于正屏时禁止画舞台。
   - RearDisplayPolicy：目标必须是明确的非主屏 ID。RearLyricsLauncher：取消时清理尚未确认显示的暂存任务。
2. 雾笺背屏：在既有 rearSafeArea 模式下缩放水滴到 25%–48%，减弱折射与高光；字迹遮罩减少透镜覆盖并提供稳定对比度。正屏参数不变。水滴模拟仍复用既有引擎，渲染阶段调整几何，不增加计时器。
3. 推荐卡：在线三张卡不再 requestCollectionPlay；本地对应卡打开现有集合。按钮改为“查看歌曲”，卡片本身也进入列表。歌单里的播放操作才改变队列。
4. 桌面歌词：取消 ellipsize，完整句子按已有逐字时间轴的已唱宽度滚动。暂停/缓冲不推进，Seek 直接定位，切歌按 epoch 清除旧句。双行新增左右分离，偶数/奇数歌词分别居左/右交替高亮，使用整行宽度。
5. 桌面按钮：右上角横排锁定/关闭小图标，视觉 14dp、触摸 28dp；顶部仅留 16dp，取消原独占大行。窗口高度同步减少，锁定后图标隐藏。splitLines 持久化并随既有视觉配置导入导出。
