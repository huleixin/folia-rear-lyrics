# 1.3.116 正屏舞台设置与配色交互

## 改动

- Android 手机的正屏歌词样式编辑器使用与背屏相同的整页布局、应用主题、安全区和标准返回栏，保留原来的预览、背景、字体、歌词动画及字幕设置。桌面弹窗保持原有入口。
- 正屏编辑器新增「主题与配色」。复用 ThemeQuickEditor，保存调用原正屏主题控制器及自定义主题持久化；背屏独立配置不被写入，跟随模式继续采用既有规则。
- 色相条原来改变白色/灰色时，饱和度为零导致 Hex 颜色不变。现在明确拖动色相时为近中性色选出可见颜色；饱和度区及推荐色仍可选择精确的黑、白、灰。父组件的节流反馈不再重置取色器内部色相，切换颜色字段或明暗配色仍重置到对应值。
- 补齐原生颜色拖动结束的 pointerup，解除编辑器的拖动状态。
- 修复主题种子快照过期：getThemeParkSeedTheme 在渲染期被 App 的 useMemo 读取，不能使用永久身份的事件回调包装。改用依赖当前主题的 useCallback，保存后再次进入编辑器读取最新配色。

## 核心文件

SettingsModal、FrontStageAppearancePage、VisPlayground：正屏页面/配色入口/返回接线；ThemeQuickEditor、FastColorPicker、nativeSettingsActions：取色、预览与结束事件；useThemeController：主题种子失效关系。沿用原配色保存、外观备份与导入逻辑，没有创建第二份正屏主题存储。

## 验证与边界

TypeScript 检查通过；32 个相关前端测试文件、304 项测试通过；912 项 Android JVM 检查通过；6 项浏览器交互回归通过。浏览器验证使用 Playwright（当前会话未提供 Browser plugin），覆盖实际 SettingsModal 的 320/393 宽度、浅色/深色、原生文档操作桥色相拖动、保存/再次进入与分级返回，以及背屏独立配置隔离。

浏览器证据不是 Android 真机证据。本轮没有连接手机，仍需覆盖安装后检查 Compose 页面滚动、安全区、拖动手感，以及正背屏实际舞台配色。未修改播放内核、歌词时钟、原生背屏卡片、AOD 调度及 Shizuku 实现。

## 手机验收

打开正屏歌词样式设置，确认整页布局与背屏一致；进入主题与配色，选白色强调色后拖动彩色色相条，确认色块/数值改变；保存后回到舞台并再次进入，检查保存值。分别编辑浅色与深色配色，注意编辑标签选择的是配色槽位，并不切换当前舞台明暗。启用背屏独立外观后分别修改两端，确认互不覆盖。

## 回滚

本轮沿用既有配置格式和键名，没有数据库迁移或清理用户数据。回滚对应的本轮源代码提交并以更高 versionCode、同签名重新构建即可；不建议通过卸载降级。
