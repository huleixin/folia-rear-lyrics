# 听屿 Android 1.3.14：凝彩背屏歌词避让

版本1.3.14；Android versionCode 27；包名io.github.huleixin.tingyu。

## 修复

- 在凝彩逐字动画、镜头运动和段落转场之后，按当前镜头的歌词整体测量并等比校正位置，避免主歌词进入摄像头或超出屏幕。默认分句与整句模式均保留。
- 反色主字、错位阴影、关键词颜色和运动拖尾使用同一变换；保留原反色滤镜的背景采样与层级，没有单独移动滤镜区域。
- 色块、线条、纸纹和装饰文字继续铺满整屏；完成的镜头在0.5秒内平滑释放阅读约束，保留原离场动画，没有右侧矩形裁切。
- 每帧先恢复原始姿态再计算，避免累计偏移。测量等待中的字形时使用局部字形及世界矩阵，防止隐藏字形的空包围盒导致错误定位。
- 复用已有安全区与镜头采样映射，预留畸变和RGB偏移空间。Sonnet辅助函数仅缩窄参数类型以供复用，原有计算不变。
- 翻译、音译按真实高度参与避让并即时更新；自动隐藏的播放控件不占固定空间。尺寸变化后保持画布CSS宽高100%；主屏不启用背屏避让。
