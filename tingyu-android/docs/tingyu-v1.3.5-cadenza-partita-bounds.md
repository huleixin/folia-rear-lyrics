# 听屿 Android 1.3.5：心象、云阶背屏边界修复

版本 1.3.5 / versionCode 18，沿用原包名和发布签名，可覆盖安装。

## 本版修复

心象的文字原本在整屏坐标中散点排列，单词进入、旋转和强调放大后会进入摄像头区域；云阶则叠加了行组浮动、字组随机缩放和单词强调，部分文字会压到摄像头下方或超出右边缘。

- 心象：在已有绘制循环完成所有单词变换后，测量当前句可见正文的最终边界，必要时等比收缩并平移到摄像头右侧。
- 云阶：在 Framer Motion 完成当前帧变换后校正当前句，保留字组和单词动画；移除背屏列容器的桌面最小高度，并收敛过大的随机字组缩放。
- 校正只作用于文字组，不裁切右侧容器；背景继续全屏。当前句结束后的退场可继续越出阅读区，不为会自动隐藏的底部控件预留固定高度。
- 复用既有安全区与等比拟合工具。连续坐标由 ref 与 DOM transform 更新，没有逐帧 React state；心象复用现有绘制循环，云阶使用 Framer Motion 的帧后阶段。
- 正面舞台保留原有排版和动画；浮名、花火、群唱以及共享背屏几何代码未修改。

- 连续切句与长英文：另测 44 个采样点，越界 0、缺失正文 0、页面异常 0。切句后模拟后续播放时钟帧，使新挂载的字组按真实播放方式接收时钟。
- 实际 `/rear-lyrics.html` 双文档结构联调：外层 iframe 为完整 347×212；心象与云阶正常渲染、切换，暂停/继续/下一首指令成功，播放控件自动隐藏且可以唤回，无页面异常。
- TypeScript 通过；111 个 visualizer 测试文件通过，1238 项通过、1 项既有跳过。
- Android assembleRelease / testReleaseUnitTest 成功，34 项原生测试通过；签名与原发布版本一致。
