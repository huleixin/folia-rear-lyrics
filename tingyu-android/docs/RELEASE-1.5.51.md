# 听屿 1.5.51

- 修复“歌词动画样式”入口图标背景颜色异常，Android 入口使用当前界面主题配色。修正设置颜色中 CSS 透明度的解析，保留真实配色预览。
- 明确动画设置的开关含义：开启表示减少动画，关闭表示正常播放；不影响音乐播放。
- “Monet 背景漂移”更名为“减少莫奈背景动画”，说明仅在对应歌词背景使用时生效；“界面微动效”更名为“减少界面动画”。
- 原生极简播放页与导航、底部播放器共用动画偏好。“跟随系统设置”开启后可响应 Android 系统动画设置变化，关闭后恢复各项个人选择。
- 移除 Android 上无实际作用的“设置页平滑滚动”，桌面端继续保留。

versionName 1.5.51，versionCode 266，正式包名 `io.github.huleixin.tingyu`。沿用原 Release 签名，可覆盖升级原正式版。

验证：59 项相关前端测试、18 项 Android 页面归属检查、类型检查通过；3 项原生回归覆盖 CSS 透明颜色及系统动画设置监听。两项旧舞台菜单测试在未修改的 1.5.50 基线同样失败。本轮未连接真实设备，覆盖升级和实际界面颜色、动画表现仍待实机验证。
