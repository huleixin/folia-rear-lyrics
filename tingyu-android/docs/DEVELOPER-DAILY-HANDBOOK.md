本手册专为日常高频操作编写，无需记忆复杂技术细节，按场景照做即可。

## 一、怎么在手机上安全登录并安装后台图标（PWA）

1. 先在已登录的**电脑后台**左侧点击 **「安全管理」** -> 点击 **「生成手机管理端 5 分钟登录链接」**。
2. 将该链接发给自己手机（微信文件传输助手等），5 分钟内在手机浏览器（Safari / Chrome / Edge）打开，即可免输长密码直接进入后台（链接打开一次即自动销毁，十分安全）。
3. **添加到手机桌面**：
   - iOS Safari：点击底部分享按钮 -> **「添加到主屏幕」**；
   - Android Chrome / Edge：点击右上角菜单 -> **「安装应用 / 添加到主屏幕」**。
   - 之后即可像原生 App 一样从手机桌面打开「听屿管理」。

## 二、怎么看用户反馈与下载诊断日志

1. 打开管理中心 -> 点击 **「用户反馈」**（手机端点击底部 **「反馈」**）。
2. 可按问题分类（播放失败、闪退、歌词异常等）、处理状态或版本号筛选。
3. 点击任意反馈单号（`TY-...`）打开详情弹窗：
   - 点击 **「查看诊断日志」** 直接在线阅读脱敏日志，或点击 **「下载诊断日志 JSON」** 保存文件。
   - 如需交给本地 AI 修复，直接点击 **「复制结构化 AI 修复任务指令」**，粘贴给电脑上的 Codex 或 WorkBuddy 即可！

---

## 三、怎么让 AI 排查问题并准备新版本（安全不误推）

直接在电脑上对 Codex / WorkBuddy 说：

- 排查问题：**「请检查最近 48 小时的用户反馈并给出修复方案」**
- 本地打包自测：**「帮我打包一个正式签名测试包，不要上传推送」**
- 准备候选版本：**「帮我准备发布新版本候选包并上传到 CNB 预发布，完成完整性校验，不要正式推送」**

> 放心：AI 只有「候选准备权限」，没有你的独立发布确认密钥，绝对无法自己向线上用户推送更新。

## 四、怎么审核并正式发布新版本（支持手机远程发布）

当候选包已在电脑上传至 CNB 并登记到后台后，哪怕电脑已经关机，你也可以随时在电脑或手机上完成正式发布：

1. 打开管理中心 -> 进入 **「版本发布」**（手机端底部点 **「版本」** -> 顶部点 **「版本发布」**）。
2. 仔细核对候选卡片上的：**版本号、更新方式（默认强制更新）、影响版本范围、SHA-256 指纹与更新公告正文**。
3. 如需改成普通可选更新或修改公告文字，可在上方表单调整保存。
4. 核对无误后，先点击 **「1. 审核确认候选」**（锁定当前安装包与公告摘要）。
5. 输入你的 **独立发布确认密钥 (`RELEASE_PUBLISH_SECRET`)**，点击 **「2. 确认正式发布（签名并推送策略）」**。
6. 系统会自动实时检测 CNB 下载直链可用性并完成密码学签名发布，客户端即刻生效！（下次开电脑时运行一句 `npm run release:sync` 即可顺手把静态镜像文件同步到 CNB 仓库）。

## 五、怎么暂停更新推送

如果新版本刚发出去发现小问题，不想让更多用户继续收到更新提示：

1. 进入 **「更新策略」** 面板 -> 选择 `正式稳定渠道 (stable)`。
2. 输入独立发布确认密钥 -> 点击 **「暂停该渠道新版本推送」**。

---

## 六、怎么紧急解除强制更新（救命开关！）

如果发出的强制更新版本在部分机型上出现严重闪退，导致旧版用户被弹窗拦住无法听歌：

1. 手机或电脑打开管理中心 -> 进入 **「更新策略」** 面板。
2. 目标渠道选 **`正式稳定渠道 (stable)`**，填写原因，输入独立发布确认密钥。
3. 点击红色按钮 **「紧急解除强制更新限制」**！
4. **立即生效**：被拦截的用户只需点一下更新弹窗底部的 **「重新检查更新」**（或重启 App），强制弹窗会立刻消失，恢复正常听歌！完全不需要等重新打包！

---

## 七、怎么查看历史版本、节点健康度与免费额度状态

- **下载节点检查**：进入 **「下载节点」**（或在「版本管理」点击 **「实时探测下载节点」**），查看 CNB 主节点与 GitHub 备用节点的状态码、文件大小与延迟。
- **发布审计记录**：进入 **「发布记录」**，所有候选登记、审核、发布、暂停、紧急解除均有不可删改的时间戳与哈希链记录。
- **免费额度与健康检查**：进入 **「服务状态」**，随时查看私有日志存储占用（上限锁定 256MB，远低于 Cloudflare 10GB 免费线，确保永远 0 账单）；如遇恶意刷接口，可在 **「系统设置」** 一键暂停反馈上传。
