# 听屿 Android 1.3.2：当前句锁进镜头右侧安全列

这一版只处理“正在唱的那一句”。其余句子的出场、散开、飞走动画保持原样，画面仍然整屏，不裁切。

## 浮名（fume）

镜头原来按整块屏幕宽度给当前打印行取景，行宽超出镜头右侧的可用列就会顶出屏幕。现在取景宽度改用安全列宽度，并把这一行的中心对准安全列中心；前后句、报纸装饰、背景仍按整屏坐标绘制。

## 经典（classic）

背屏上不再对每个字做随机位移、旋转和缩放抖动，主句居中落在安全列内；正面舞台的散点风格不变。

## 花火（hanabi）

右移量原来按“画面中心”计算，但每种排版的文字中心并不都在画面中心，所以有的镜头仍压到镜头下方、有的冲出右边界。现在按每个镜头自己的文字中心计算偏移，烟花、贴纸、胶片条保持整屏。

## 验证

- TypeScript 通过；visualizer 测试 1224 项通过、1 项跳过。
- Android assembleRelease 成功，34 项原生单测通过。
- 本地预览台截图确认：浮名主句完整落在右侧列内、上一句仍在上方；经典主句居中不越界；花火文字层随镜头排版右移。预览台为 Chrome+SwiftShader 近似渲染，仍需真机确认。
