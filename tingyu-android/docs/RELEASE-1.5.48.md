# 听屿 1.5.48

- 移除音频空间上限类目和所有容量档位，默认无总容量上限；升级后清除旧容量设置，完整音频不会因超过旧8GB阈值被淘汰。
- 将本机缓存数量/占用与当前歌单下载进度分开显示，补齐跨歌单共享歌曲的统计；歌词和封面详情分别核对已有文件，避免未执行任务错误显示为零。
- 缓存操作改为明确按钮：查看任务、暂停/继续下载、失败重试和清理。任务列表保留按歌单/状态筛选、每页20首。
- 明确「播放歌单时自动预缓存」只决定自动提前下载内容；仅歌词与封面不影响边听边存或歌单操作中的手动整单缓存。
- 歌曲音质标签后增加已缓存圆圈勾，按当前音质和音源策略核对完整文件，清理后自动更新。
- AutoMix 复用完整离线音频，提示和管理入口与离线缓存统一，移除旧开关对Android分析流程的影响，避免分析重复下载远程音频。
