# 播放器逐帧参考修正 · 1.5.7

参考：用户提供的 video(13).mp4，1220×2656，118 帧，时长约 3.913 秒。以实际解码时间戳分析，不假设录屏严格恒定 30 FPS。分析缩小至 305×664；原视频和图像仅保存于本地 outputs，不提交仓库。

## 1.5.6 的差异

1.5.6 将整张播放页从迷你封面处等比缩放，封面、文字、控件共用一个几何进度。这与参考中外壳、封面和内容分轨的过程不一致。

## 实际修正

- 外壳从真实迷你栏的矩形向上展开，宽度只小幅增加；保留参考的大圆角及收尾时机，不压扁文字。
- 封面使用真实来源 / 目标坐标，中心 X、中心 Y 和尺寸独立驱动。保留真实 MinimalArtworkView，借助当前 Compose 1.10.3 已有的 renderInSharedTransitionScopeOverlay 越过 pager 裁剪；不复制封面、不新增图像加载器、不创建第二个播放器。
- 曲线来自第二次展开与第一次收起的测量样本；单调 Hermite 插值保持采样点、兼容 60/90/120/144 Hz。展开的主要位置约在 566ms 落定，圆角收尾保留至 980ms；收起独立使用 500ms 轨迹。
- 标题、歌曲信息、进度 / 控件分阶段显现；关闭时与真实迷你栏交接。入场中返回会从当前几何与透明度继续。
- 暂不把参考应用的字体、配色、封面排版换入听屿，终态仍为现有听屿 UI。此处还原的是交互运动。

代码：chrome/SaltPlayerTimeline.kt、MinimalPlayerMorph.kt、MinimalCoverOverlay.kt；接入 ComposeChromeHost、MinimalPlayerScreen 与 MinimalCoverPage。

收起尾段的外壳已与迷你栏材质混合，边界无法完整分割时按已测起止边界收敛；封面继续使用模板匹配测量。圆角收尾取自第一段展开，不能把几何数据视作整个画面的逐像素复刻。

## 独立片段对照结果

使用未参与标定的第一次展开 16 帧与第二次收起 8 帧；分别对齐到录屏 288ms、3102ms。封面四边坐标的均方根误差为 1.052 / 1.791 分析像素，最大误差为 4.595 / 6.575 分析像素（分析宽度 305）。这项结果仅说明生产几何轨迹与录屏接近，不包含听屿字体、配色、堆叠装饰或真机调度误差。

动画前段暂缓封面呼吸、堆叠背景和光效，位置落定后恢复听屿原有效果，避免原有微动叠加到标定轨迹。

## 同时修复

歌手入口复用已建立的 minimal 会话动作监听，避免额外异步监听注册 / 拆卸时丢事件。按实际显示的歌手名称匹配结构化 ID，缺少资料时仍调用现有目录解析；重复点击合并，切歌或页面销毁后丢弃过期结果。姓名、分隔符和箭头均可触发，原生测试使用真实触摸事件验证。

极简页与歌词舞台往返改用 detour 布尔呈现和同一个原生时钟，实际 WebView 与原生舞台控制条同步位移；不依赖 400ms 后会消失的 JS 阶段标记；原生动画结束回传 stageMotionFinished 后才移除网页舞台，每次往返携带独立 token，迟到回执即使方向相同也不会结束新过渡。桥断开时有 1400ms 上限，浏览器仍沿用 400ms。仅在原生极简页握手成功时启用，HTML 临时回退仍保留原动画。过渡期间底层保留极简页，防止浏览页盖上来。

## 验证边界与复现

- SaltPlayerMotionTest 对记录的展开 / 收起关键帧检查真实生产几何，容差 1.5 分析像素，并验证高刷新率插值、反向中断、阶段标记丢失和减少动态效果。
- 测试导出 android/app/build/reports/salt-player-motion.json。使用 dev/analysis/compareSaltPlayerFrames.py 对未用于标定的第一次展开与第二次收起进行封面轨迹对照，允许对齐录屏起始时间；输出均方根误差及轨迹叠加图。
- MinimalPlayerFooterTest 使用原生实际触摸验证歌手姓名及右侧箭头；nativeMinimalArtist.test.ts 覆盖名称回退、ID 对齐、重复点击、切歌、卸载和不可用反馈。
- 保留页面归属、舞台交接、设置返回与播放器状态回归。未修改 Media3、歌词时钟、Folia 逐字核心或背屏歌词链路。

本机没有已连接 Android 设备或可用模拟器。Robolectric LEGACY 测试与几何对照不等同于设备截图 / GPU / 实际帧率验证，不能宣称已逐像素还原真机观感。安装本地 1.5.7 APK 后仍需与原视频对照一次。

API 核对：[AndroidX SharedTransitionScope](https://developer.android.com/reference/kotlin/androidx/compose/animation/SharedTransitionScope)；使用已有 API，无依赖升级。
