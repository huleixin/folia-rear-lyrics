# 听屿 1.5.6 · Liquid Motion 正式版

Android versionCode 221；正式包名 io.github.huleixin.tingyu；沿用原发布签名。基于 1.5.5（029d2023）的全局动效施工和本次回归修复。对应源码以 v1.5.6 标签为准，APK 构建标识需与该提交一致。

## 覆盖与补全

| 交互 | 最终实现 |
| --- | --- |
| 迷你栏 → 极简播放页 | 测量迷你封面与目标封面；同一画布等比缩放、移动、圆角变化；控件分层显现；反向收起 |
| 迷你栏 → Folia 舞台 | 封面来源的画布变形；保留歌词渲染器与最终视觉 |
| 歌单 / 专辑 / 最近播放卡 → 详情 | 原生 SharedTransitionLayout / sharedElement，稳定入口身份；离屏或无来源时安全降级 |
| 推荐、资料库、搜索、歌手、本地 / 下载 / 最近等目录 | 统一原生路由推进 / 返回；保持页面状态 |
| 全部设置二 / 三级页面 | 共用 SettingsFlowPage；确认框保留模型到退出结束 |
| 歌曲操作、队列、定时、音质、音效、歌词工具、支持面板 | 原生独立遮罩 + 弹簧容器；内外点击、返回、退出保留 |
| 搜索音源 / 资料库排序 / 通用排序下拉 | LiquidDropdown + LiquidPopup；统一缩放淡入、反向退出、减少动态效果 |
| 搜索分类 / 音源分类 | 单个连续移动的选中指示器 |
| 搜索历史 / 热榜 / 歌手简介 | 按压反馈、容器高度连续变化；减少动态效果时直接落定 |
| 设置开关 / 复选框 / 选择器 | 原生状态动画与统一反馈；设置排序采用稳定 key + 局部 animateBounds |
| 支持渠道选择 | 单个弹簧移动的选择表面 |
| 极简播放器更多菜单 | 保留既有定位，统一时序并补齐减少动态效果 |
| 账号登录 / 平台切换 / 确认框 | Motion 弹簧与统一参数、退出保留、应用 / 系统减少动态效果 |
| 收藏 / 播放模式 / 队列重排增删 | 图标状态过渡、惰性列表 animateItem，拖动本体跟手 |
| 经典与冰川深浅色主题 | 当前可见色可中断插值；不同渐变节点数先对齐，避免数组越界 |

主题日志中两次 ArrayIndexOutOfBoundsException 的原因是用目标渐变的第三节点索引只有两个节点的来源。修复为公共均匀节点采样；端点保留原渐变，快速切换从当前显示色继续。

没有新增运行时依赖，也没有升级 Compose / Navigation。Motion 与 Motion Primitives 的 MIT 文本继续随包分发；AndroidX Compose 为 Apache-2.0，项目整体许可维持 AGPL-3.0。详见 LIQUID_MOTION_NOTICES.md。

## 验证

- TypeScript / theme:check、Android 页面归属 18 项通过。
- Android 定向测试 55 项通过：主题全部组合与反向切换、实际渐变消费、封面位置 / 逆向 / 无来源、Popup 退出 / 重开 / 屏幕边缘与 RTL 避让、页面保留、舞台交接、字幕与面板状态。
- Web 舞台与返回 7 个单元测试文件共 23 项通过。
- 浏览器动效 7 项通过，涵盖菜单、抽屉、确认框、焦点、外部关闭、快速重开与减少动态效果；字幕 2 项通过，涵盖主屏横屏控件显隐与独立背屏位置。
- npm run audit:motion：17 个源码合同检查、46 个原生相关模块（含绘图 / 模型等明确排除项）；清单见 LIQUID_MOTION_AUDIT.json。源码扫描用于防止入口遗漏，不等同于视觉或性能测试。
- 浏览器没有独立 Browser 插件，使用仓库 Playwright + 已安装 Chrome；已检查真实字幕截图。原生测试使用 Robolectric LEGACY 图形模式。

构建命令：npm run build:android:release（必须完整生成并同步新网页资源；不可用 stale-assets 参数制作发布包）。正式发布另校验签名、版本、包名、构建标识与全部网页资源指纹。

本机无连接的 adb 设备、无可用模拟器，未声称通过真机帧率、预测返回、键盘、双屏、横竖屏和前后台视觉测试。封面展开与椒盐参考的最终观感仍需设备验收。

保护：未修改原流动底栏、Folia 逐字核心、歌词数据源 / 时钟、Media3、背屏与灵动岛歌词数据链路。背屏控制页只补按钮反馈，背屏歌词效果保持独立。
