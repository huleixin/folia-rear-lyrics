# 听屿 Android 1.3.3：背屏参考代码接入测试版

版本 1.3.3 / versionCode 16。沿用包名及原发布签名，可覆盖安装。

## 本版范围

- 复用 wmqc97/folia-android 提交 `4d86ad210d3004a61fce1378a253220b05c7fb8c` 的背屏构图几何工具及几何测试，保留署名与 AGPL-3.0 许可说明。
- 摄像头边界采用参考项目的物理像素到 CSS 像素比例换算。默认基准为小米 17 Pro Max 的 277/976，支持显式传入物理边界；其他设备仍需真机校准。
- 将阅读区和绘制区分开。花火恢复整屏场景、移除内部阅读区遮罩；不创建额外的 overscan 位图，避免直接套用参考项目后增加绘制面积。
- 浮名在弹簧相机变换后，仅校正当前句的完整文字边界，同时修正文字光栅缓存的可见范围。前后句、背景及装饰继续在整屏活动。
- 花火在场景、旋转和段落变换完成后，检查当前镜头歌词字形边界，必要时等比缩小和平移。贴纸、烟花和其他文字动画保留整屏区域。
- 修正群唱背屏误取整首歌最后一句的问题，改为显示当前句。字幕也按照右侧安全区放置。
- 沿用并纳入源码快照中此前已有的云阶背屏折行调整；心象等待文字容器显式区分背屏与正面尺寸。

## 验证与证据

- TypeScript 检查通过。
- visualizer 单测：110 文件通过，1235 项通过，1 项既有跳过。
- Android `assembleRelease testReleaseUnitTest --offline` 成功；34 项原生测试通过。
- Chrome + SwiftShader + Playwright：全部 15 样式在 347×212 CSS 视口、反馈句“思念的人住在弯月亮”下检查两个采样时刻；六个重点样式补充 329×208 长句、904×572 短句检查。904×572 为较大 CSS 视口压力样本，不等同于手机物理像素。
- 生产结构联调：实际 `/rear-lyrics.html` 外层背景 + 内层 iframe 均为整屏；模拟原生数据通道，暂停、继续、下一首指令成功；控件自动隐藏且可点击唤回；花火 Canvas 为完整 347×212。联调无页面异常。
- 未连接 Android 真机或模拟器。硬件摄像头边界、真实 WebView 的全部动画、发热与电量没有实测结论。
- 随 Release 提供预览截图、原始量测 JSON、源码和 SHA-256 校验文件；黄色竖线仅在截图拼图中标记参考摄像头右缘，不会显示在 App 中。
