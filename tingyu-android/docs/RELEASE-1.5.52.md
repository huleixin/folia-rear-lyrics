# 听屿 1.5.52

- 将第三方音源扩展入口移至「设置 → 音源与系统歌词 → 高级扩展 → 实验性功能」，新用户默认关闭。
- 首次开启扩展及每次导入音源前增加风险确认；未勾选确认项不能继续。
- 已启用音源的老用户保留原有使用状态；关闭扩展后保留配置，重新开启可恢复，并可管理、禁用或删除音源。
- 关闭扩展时停止使用相关第三方音源，撤销旧播放地址及后台队列地址，防止继续沿用已停用的音源。
- 移除其他直接导入、快捷音源入口及设置子页顶栏的通用帮助问号，减少误触。设置首页仍保留「关于与帮助」。

使用原有正式签名，可覆盖安装。第三方脚本由用户自行提供，请仅使用可信且有权使用的音源。

验证：音源与播放相关回归 207 项通过；类型检查、原生编译通过。设置全量回归存在 3 项既有失败（旧菜单断言及缓存页锚点），本次未修改相关功能。未完成真机视觉与转场验收。
