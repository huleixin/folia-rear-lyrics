# 听屿 1.5.57 封面与背景转场修复

基线 1.5.56 / 72390ac1，版本 1.5.57 / 272。

## 原因及修复

- 沉浸宿主未提供 LocalMinimalCoverOverlay，导致 immersiveMovingCover 提前返回。现复用宿主已有的 SharedTransitionLayout，不创建第二套播放器或图像加载器。
- 退出开始时 active=false 同时停止封面变换。现在交互权限和保留绘制分开，退场期间继续飞行；下拉释放时不再因交互状态变化清零拖动位置。
- 外壳之前直接绘制黑底和沉浸背景。现以当前界面的迷你栏表面色为过渡底色，借透明度显露下层页面；沉浸配色随同一进出进度逐渐混合，整个外壳按经典时间轴透明退场。
- 首次歌曲配色在后台提取后初始化网格，避免先显示默认紫色再换为歌曲色。复用现有背景缓存；首次配色就绪有短暂渐变，减少动态效果时立即应用。
- 暂停时允许生成一张静止背景，后续停止动画，避免无缓存时首次显示空背景。

## 验证

- Android 页面归属：18项通过。
- 原生：10项通过，包括经典几何兼容、颜色混合连续性、取消拖动和实际 Compose 进出场像素检查。
- 实际宿主渲染测试不从外部提供共享封面图层，能捕获此次遗漏。使用测试位图扫描实际绘制位置和尺寸，覆盖靠近迷你栏的起点、进入中途、展开完成、下拉中途、取消回弹、退出禁用交互后的中段与尾段。图片为测试数据，不是实机效果证明。
- 竖横屏封面、歌词、队列以及歌词舞台命令路由回归通过。
- 正式包使用原签名；发布前检查版本、证书和公开下载包哈希。
