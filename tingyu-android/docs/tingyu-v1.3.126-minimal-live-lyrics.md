# 听屿 v1.3.126：极简封面实时歌词

基于 v1.3.125，versionCode 从 148 升至 149。

## 用户可见变化

- 极简封面页在歌曲信息下方显示当前歌词。
- 歌词沿用现有播放歌词与 `lyricCurrentTime`；只在当前句变化时更新，不创建独立计时器。
- 点击歌词直接切换到右侧极简歌词页，可查看完整歌词并沿用现有逐句交互。
- 封面页歌词最多排两行，长句自动省略；完整文本仍可在右侧歌词页查看。
- 没有当前歌词时不占位；切换至其他页面、播放器被覆盖或应用隐藏时停止订阅。

## 范围

未修改播放器、队列、Media3/兼容通道、歌词解析与时间轴、原生背屏卡片、AOD 或 Shizuku。
