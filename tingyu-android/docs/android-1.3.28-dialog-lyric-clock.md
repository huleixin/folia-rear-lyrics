# 听屿 Android 1.3.28：音源弹窗与歌词时钟修复

## 音源弹窗

截图中的下半部分重叠来自原生设置文档的导出，而非弹窗的 HTML 排版。Chromium 可以为关闭的 `details` 后代返回布局矩形，原生绘制列表此前也导出了这些不应显示的正文与控件。本次只遍历关闭折叠块的第一个直接 `summary`，展开后再正常导出内容，恢复原来的滚动容器与后续按钮布局；不改变配色、字号和按钮设计。

回归覆盖真实设置文档与音源管理弹窗，393×852、360×640、852×393、1024×768 四种尺寸下检查折叠、展开、滚动区域、文字与操作按钮不重叠。闭合状态的正文导出断言在旧版失败，修复后通过。

## 歌词时序

原生进度原来在 JS 收到消息时重新起算，传输延迟会让正在连续前进的显示时钟倒退。已在测试中复现：显示到 13.12 秒后收到延迟 70 毫秒的 13.05 秒快照，旧实现退回 13.05 秒，可能让跨过换句/逐字边界的动画重复触发。

本次原生快照携带采样时的系统时间，JS 只为正在实际输出且未暂停的有效快照补偿传输时间，随后仍使用本地单调时钟插值。缺失时间戳、超过 1 秒的旧包、超出补偿范围的系统时间调整、暂停和缓冲状态不补偿。真实拖动/回退保持生效，没有使用禁止倒退的方式掩盖 seek。

未修改 Media3 的解码、选源、音频输出、切歌和命令时序；未降低帧率或关闭主题特效；背屏和主屏继续共用现有逐字时序。莫奈、商籁、凝彩、花火在浏览器下反复打开/关闭更多菜单未发现歌词画布被销毁重建。
