# 听屿 Android 1.3.33

本版基于 1.3.32，只处理播放、后台续播、本地列表及封面问题。歌词闪烁的图形隔离实验另行提供诊断包，不宣称本版解决了闪烁。

## 修改

- 补齐系统媒体会话的进度跳转回调；原生引擎直接跳转并回传结果，兼容通道经原有播放控制处理。通知栏使用原生解码器时钟，过时的界面进度不能撤销系统跳转。
- 将已解析的后续播放地址提前交给 Media3 的原生播放列表，曲目边界由 Media3 自动切换，通知栏元数据也由原生同步；界面恢复时接收当前原生曲目，不重新准备、倒回已经播放的歌曲。
- 在线预加载窗口最多三首；纯本地队列最多预交接后续 999 首。随机播放只预交接已确定的下一首；扩展 beforePlay 拦截器存在时不绕过拦截器。未解析/失效地址、窗口耗尽、Navidrome 仍需原有解析链补充，不能将其称为完整原生音源迁移。
- 下一首不再等待封面缓存及歌词请求完成才开始播放。EOF 后的兼容交接保护最长 20 秒，开始出声、暂停或销毁时提前释放；没有长期额外持有 CPU 锁，也不恢复隐藏页面的视觉绘制。
- 本地文件夹下同时显示子文件夹及当前目录的歌曲，支持筛选、分页和直接点播。
- WebView 专属本地封面地址转为可供原生显示的缓存缩略图；已完成的封面不等待整个批次，返回页面立即复用已完成缩略图。网络封面继续使用共享 Coil 内存/磁盘缓存，并添加一致的请求/占位缓存键。
- 频谱 FFT 从音频输出线程移到单一工作线程，最多一个任务在途；Hann 窗预先计算。后台/退出舞台仍停止频谱计算，保持现有视觉采样频率、音频卸载策略和歌词特效。

## 验证及限制

- TypeScript 检查通过；定向前端测试 39 项通过；Android JVM 测试 128 项通过；签名校验通过，沿用正式签名和包名。
- JVM/浏览器测试不代表小米 17 Pro 的锁屏调度、Media3 解码器或 GPU 已验证。未连接手机。
- 需要真机验证通知栏连续拖动、锁屏至少跨三首播放、本地文件夹列表、反复进出舞台时的听感。进出舞台卡音是否完全消失尚未确认；音频卸载与 PCM 频谱模式之间的切换仍保留，不能在没有设备测量时断言它完全无间断。
- 歌词闪烁根因未定位；未证明 `graphicsLayer(alpha=0.999f)` 对 WebView 有效，且本版没有继续叠加整屏合成层。
