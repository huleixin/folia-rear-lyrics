# 听屿 Android 1.3.30：实机反馈修正

1.3.29 已安装但三个问题仍出现，说明上一版只修到了部分路径。本次按实机渲染链补上：

## 歌词闪烁

- 浏览器可视化桥也加入 250ms 的单调保护：普通帧抖动只能让歌词时钟停住，不会回退；真正拖动进度（跨度大于 250ms）仍立即生效。
- Android 默认使用 `drop-shadow` 合成路径绘制流光/云阶的辉光，避免 WebView 对逐帧变化的 `text-shadow` 重复生成字形缓存。
- 新增桥接层测试：11.9 秒的晚到快照不会让 11.5 秒歌词回退，3 秒的真实 seek 会立即通过。

## 洛雪音源一分钟

- 保留 1.3.29 的“提前结束后续取一次并回到原位置”逻辑。
- 检查了用户提供的音源脚本：它返回 `yinyue.haitangw.net` 的固定地址；在本机网络请求时，该服务对有效 QQ 歌曲返回 `{"code":0,"msg":"请求异常"}` / HTTP 404。若手机上仍只能播放一分钟，需要确认脚本服务是否只返回试听片段或已限制时长；应用不能把第三方一分钟试听扩展成完整音频。
- 读取超时保持 60 秒，避免缓冲排空被误判为断流。

## 音源弹窗

- 1.3.29 的透明修复依赖 `:has()` 选择器和网页遮罩，实机仍未生效。1.3.30 直接把不透明背景、遮罩色写成 ThemedDialog 的内联样式，并补上 `role=dialog` / `aria-modal`，确保原生设置文档捕获时也拿到实色底板。
- 锁定 `html`/`body` 滚动；遮罩和面板使用 `touch-action`、`overscroll-behavior`，并在 document 层拦截面板外的 wheel/touchmove 链到底层页面。

## 验证

- 相关单测通过；TypeScript 检查通过。
- 浏览器真实弹窗 13 项检查通过，八种歌词舞台渲染无运行时错误。
- Android JVM 测试 124 项通过，发行构建及 v2/v3 签名校验通过。
- 仍未连接手机；本轮弹窗改动通过内联样式和原生文档捕获路径同时覆盖，但实机效果需要安装 1.3.30 验收。
