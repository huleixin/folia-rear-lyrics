# Compose 第一阶段：beta.6 修复构建

本阶段将手机主界面的导航栏、播放小组件和歌词舞台底部控件迁移到 Compose。推荐、资料库、搜索、设置、音源、播放引擎及歌词舞台仍由现有代码提供；背屏与 LSP 不参与这次替换。

## 构建与回退

预览包版本为 1.3.20-beta.6（39）。前端构建设置 `VITE_TINGYU_COMPOSE_CHROME=true`，Android 构建设置 `TINGYU_COMPOSE_CHROME=true`。旧玻璃实验的 `TINGYU_GLASS_LAB` 与 `VITE_TINGYU_GLASS_LAB` 应保持 `false`。随后按现有流程构建网页、复制 Capacitor 资源、构建并签名 APK。

两个 Compose 开关默认关闭。普通构建继续使用现有控件。预览包在 Android 12 及以上启用原生模糊，在 Android 13 及以上增加折射；不支持或桥接初始化失败时保留网页控件。WebView 调试仅在 Debug 构建中开放，Release 包不开放调试入口。

## 数据与生命周期

- 一个稳定的 ComposeView 通过 AndroidView 承载原有 WebView，三组原生控件共用 Kyant Backdrop 的背景层。无逐帧截图、PixelCopy 或 JS 位图采样。
- 网页保留原控件的位置与布局。冷启动保留完整网页控件，原生完成对应会话、修订的实际绘制后才接管；两秒内未绘制则关闭该原生区域并保留网页控件。切页退场时完整裁去旧控件的绘制区域，避免留下孤立模糊底板。按钮继续调用现有播放、队列、导航和音质操作。
- 元数据和布局按事件同步；稳定播放的进度锚点间隔为两秒，跳转时立即同步。进度环、拖动与按钮反馈在原生侧处理。
- 模态窗口、设置、搜索、应用后台和隐藏的舞台不显示原生控件。舞台右上角菜单不遮挡播放控件，保留底部原生控件；点击原生控件时关闭菜单。隐藏更新可越过尚未完成的绘制回执，旧回执不能重新显示控件。后台时卸载控件组合及其时钟。会话与歌曲标识用于拒绝过期操作。
- 缺失进度锚点时最多外推 2.5 秒，防止原生进度无限自行前进。静止时无常驻布局轮询。

## 验证范围

本机桥接测试覆盖队列不进入舞台、弹窗避让、设置与搜索切换、旧会话隔离、失效回退，以及 320/393/1024 像素布局。单元测试覆盖进度节流、无空转、退出清理和长拖动期间禁止自动隐藏。

这些测试不替代 Android 上的画面检查。WebView 背景能否被正确采样、实际手势体验、帧率、功耗和不同厂商的兼容性，需要可运行的 Android 环境验证。不能用浏览器模拟桥接的结果宣称原生玻璃已通过视觉或性能验证。
