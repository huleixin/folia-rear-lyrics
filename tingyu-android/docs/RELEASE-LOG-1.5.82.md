# 听屿 v1.5.82 (Build 298) 发布记录

- **版本号**：`1.5.82`
- **versionCode**：`298`
- **发布渠道**：`testing` 验证通过后正式推送至 `stable`（启用强制更新 `minSupportedVersionCode = 298`）

## 核心变更摘要

1. **修复下载节点长期显示「待检测」**：
   - 修复后台前端 `node_type` 字段匹配不一致（`cnb` / `github` vs `cnb-primary` / `github-backup`）、发布时未持久化节点探测结果及缺少 30 分钟 Cron 定时巡检的问题；
   - 建立「部署后首检 + 每 30 分钟 Cron 自动巡检 + 发布即时回写 + 后台一键手动检测」四重机制，统一五种中文状态（`正常`、`异常`、`检测中`、`待配置`、`数据过期`）。
2. **新增官方版本下载统计与每日快照**：
   - 自动同步 GitHub Releases 全部 `.apk` 附件 `download_count` 并排除源码包；
   - 核实 CNB Releases OpenAPI 暂未开放附件 `download_count` 字段，后台诚实标记为 `暂无统计数据`（绝不伪造为 `0`），并单独统计软件内更新经 CNB / GitHub 节点实际完成的次数。
3. **新增轻量化匿名运营统计与开发者管理中心重构**：
   - 客户端新增 `TelemetryManager.kt`（严格默认关闭 Opt-In，仅采集随机匿名安装编号与基础版本/系统型号/更新漏斗，低功耗 10 分钟心跳 + 服务端去重 + 40,000/日独立写入预算熔断保护）；
   - 开发者管理中心新增一级导航「运营统计」，重构「数据总览」为四大分区与 6 张核心指标卡，状态文案全量中文化，严格区分正式版、测试版与待发候选版。
4. **修复两个客户端页面导航异常**：
   - 修复 `音乐平台账号` 返回时底板误解析为 `appearance`（视觉设置）导致闪现的问题；
   - 修复从 `搜索` 打开完整播放器再返回时底部导航选中态误落回 `selectedTab`（资料库/推荐）再滑向 `搜索` 的问题，完整保留真实切换一级 Tab 时的液态流动动画。
