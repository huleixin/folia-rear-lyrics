# 听屿 Android 1.3.1：整屏背景 + 当前句避让镜头

按用户澄清修正架构：整个背屏都是歌词动画区域，不能把画面裁进一个框；只有正在演唱的那一句需要落在摄像头右侧。

## 改法

- 撤掉 1.3.0 里把整个渲染器包进阅读区的容器。背景、装饰、粒子、拼贴恢复整屏绘制，可以经过摄像头下方。
- 内容层不再有裁切容器：容器宽度用于排版换行，`overflow` 保持可见，飞出、旋转、散开的字可以越界绘制。
- 当前句的排版锚点移到镜头右侧：DOM 样式（默认、华彩、云阶、气泡、静态、倾斜）用绝对定位的内容层；花火只平移文字容器，烟花、贴纸、胶片条保留整屏坐标。
- 垂直方向不再为自动隐藏的播放控件预留空间，只留很小的上下边距。
- 保留 1.3.0 的画布等比修复：背屏不套用 320×240 的最小画布下限。

## 仍需继续的样式

商籁、凝彩、绘光、烟雾、环形、莫奈、钟摆的文字与场景仍在同一画布/同一容器中，当前是整屏居中排版，可能靠近摄像头。这些需要把“文字层”从各自场景里拆出来再右移，未在本次完成。
