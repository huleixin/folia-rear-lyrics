# 听屿 Android 1.3.8：莫奈背屏排版修复

版本 1.3.8 / versionCode 21，沿用原包名和发布签名，可覆盖安装。

## 修复

莫奈仍沿用桌面海报布局：歌词从整屏左侧展开，歌词栏最低高度为 280 CSS 像素，加上歌手、标题和专辑头部后，内容整体超过约 212 CSS 像素高的背屏。结果是当前歌词被摄像头遮挡，并被挤到屏幕下方。

- 背屏使用独立的紧凑舞台，按真实安全区宽高安排歌词栏，不再把桌面海报头部和封面列挤入背屏。主屏海报和封面功能保留。
- 复用原有莫奈歌词栏、前后句滚动、逐字扫色、发光、翻译/音译与字体配置。当前句在摄像头右侧、背屏中部显示；长句按实际宽度换行，并根据全文高度适配字号。
- 背景、浮动装饰和音频可视化保持整屏绘制逻辑；歌词栏允许前后句动画越出阅读区，不添加右侧裁切框，也不为自动隐藏的底部控件永久预留空间。
- 去除背屏歌词栏的桌面最低高度和顶部/底部遮罩。首帧直接采用真实尺寸，避免先用桌面尺寸排版。
- 切句开始时，当前句仍可能处于从屏幕下方滚入的途中。只约束当前句的最终纵向 transform，保证它在进入演唱状态时完整可见；其余行继续滚动。该处理不裁切文字，也不逐帧读取 DOM 尺寸。
- 字体测量只在句子、字体、字号或尺寸变化时重算，复用现有测量缓存及字体加载通知；连续动画沿用 MotionValue / Framer Motion，不新增高频 React state 或动画循环。
- 没有修改摄像头几何、原生同步、其他歌词样式或已精简的设置项。

- Chrome + Playwright：329×208、347×212、393×249 三种背屏尺寸，1/1.5 两档字号，每句五个演唱阶段，共 180 个正文边界采样通过。
- 连续切句与长句另测 24 点；英文按整词/完整单词输入另测 16 点，均无正文缺失、越界或页面异常。
- 四组切句开头的逐帧检查通过，修复了原先约 100 毫秒内正文可能从底边外滚入的问题。
- 实际 `/rear-lyrics.html` 双文档背屏：完整 347×212 iframe；暂停、继续、下一首、控件自动隐藏和唤回正常，无页面异常；另检查主屏莫奈海报预览。
