# 听屿 Android 1.3.11：镜台背屏歌词避让

版本 1.3.11 / versionCode 24，沿用原包名和发布签名，可覆盖安装。

## 修复

镜台使用真实 3D 文字与移动摄像机。原取景仅考虑完整画幅，侧移、推进和文字透视变化会使当前歌词进入实体摄像头区域或超出屏幕；简单修改初始位置无法持续保护读头。

- 对当前歌词测量字身墨迹范围，在原运镜完成后计算其实际屏幕投影，以等比缩放、平移保持整句位于摄像头右侧。保留原透视和逐字跟唱，不添加平面歌词副本。
- 长句按原有定时单元换行，保持字符、单词的时间和行内间距。短句平衡换行，避免末行孤字；平衡排版不会额外增加一行。
- 新歌词挂载时在首次绘制前完成定位，避免切句首帧使用原始位置。每帧均从原始姿态重新计算，避免上一帧的修正累积成缩放抖动。
- 当前歌词保持可读，不随远景雾化而消失；远近景、粒子和上下文歌词仍沿原路径使用完整背屏，不在安全区边界增加裁切。
- 为实际显示的翻译、音译按其真实高度留出空间。播放控件和模糊的后续歌词提示不占固定排版空间。
- 主屏继续采用原有单行 3D 排版和雾化行为；其他歌词样式不参与本轮改动。
- 复用原场景帧循环和通用安全区工具。新增定位只进行矩阵运算，不增加逐帧 React 更新、DOM 测量或文字栅格化；字幕高度在内容、字体或尺寸变化时通过观察器更新，卸载时清理。
