# 听屿 Android 1.3.12：绘光背屏歌词避让

版本：1.3.12；Android versionCode：25；包名：io.github.huleixin.tingyu。

## 修复内容

- 绘光的主歌词按摄像头右侧安全宽度排版，长句继续使用原有测量和自动折行。
- 在场景运镜与段落转场完成后，按实际字形精灵的屏幕边界做等比适配，避免当前整句移到摄像头下或越过右边缘。
- 字旁光晕、闪点、追字光斑和十字爆闪跟随同一变换，保留逐字点亮、旋转与散开动画。
- 换行前后各0.5秒平滑交接避让；每帧先恢复原始姿态，避免修正累计造成缩放或位置抖动。散开的上下文歌词与光束、线稿继续使用整屏，没有右侧裁切容器。
- 仅为实际显示的翻译/音译预留空间；自动隐藏的播放控件不参与固定布局。
- 提取原镜台字幕测量逻辑为共享hook，原镜台入口保留兼容导出，测量规则不变。主屏不启用背屏避让。
