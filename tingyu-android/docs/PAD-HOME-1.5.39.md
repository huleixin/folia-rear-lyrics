# Pad 推荐页方形封面预览 1.5.39

基线 d7cff545（1.5.38）；versionCode 254；分支 feat/tablet-adaptive，未合并 main。

## 布局

- 宽屏上半区改为等宽两栏，每日30首相较原来的 1.65:1 分栏约收窄 20%。最近播放标题独立放在封面行上方，首排封面与推荐卡顶部对齐。推荐轮播、进入歌曲和更多动作沿用原实现。
- 最近播放保留两行，按窗口宽高计算列数与正方形封面尺寸。1280×854dp 示例为四列，1280×1000dp 示例为三列；不会拉伸成长方形填满区域。
- 我的歌单只显示一行，按空间计算数量。1280×854dp 示例七个，1024×768dp 示例六个；更多歌单通过现有“全部”进入资料库。已加载的歌单模型没有截断。
- 封面采用 1:1 容器与等比完整显示；非方形原图留背景补齐。保留圆角。搜索及其他页面共用图片控件仍默认使用原来的缩放策略。
- 首页按实际底部播放条边界分配高度，常规横屏首屏无需纵向滚动。极矮窗口可滚动页面，但歌单不会出现第二行。
- 最近播放的“全部”显示完整的可滚动历史列表，不受首页两行限制。手机、Pad 窄窗口及竖屏继续使用已有页面布局。

## 验证

- 原生定向测试 12 项通过：PadHomeDensityTest、PadPagesTest、HomeHeroEntryRenderTest。
- 断言包括封面宽高相等、首排顶部对齐、歌单同一行、常规横屏无隐藏滚动范围、卡片避让播放条、不同窗口列数、全部/歌曲/歌单动作与完整历史访问。
- 原生截图检查经典浅色、冰川浅色/深色、较小横屏、较高窗口、竖屏、分屏和手机。使用真实 Compose 页面及推荐素材；专辑图为离线示例封面，只存在于测试中。
- Android 页面归属与门控检查 18 项通过。生产改动仅涉及原生布局和版本信息。
- 构建、签名、APK 校验值及最终提交见随安装包提供的 summary.json。
