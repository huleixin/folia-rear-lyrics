# 听屿 1.5.58 跟手转场与背景连续性

基线：1.5.57 / 8675f1347385c349f34f3d386af15fab273c9985。版本：1.5.58 / 273。

## 改动

- 歌词页底部控制区域曾对同一背景追加全宽矩形实时模糊，形成明显横向分界。移除此重复图层，保留控制区点击拦截和歌词边缘渐隐；歌词、封面、队列继续共享已有动态背景。
- 新增宿主持有的 ImmersivePanelState。迷你栏上滑和全屏下拉共用可逆的 0–1 进度；拖动暂停时保持当前位置，反向拖动连续返回。松手按位置及方向速度落定，取消回到手势开始时的目标。
- 点击展开、收起和返回走同一进度及现有弹簧。正在自动展开或收起时可以重新抓住。到迷你栏端点后才提交路由收起，避免先卸载页面造成封面闪退。
- 面板裁剪、圆角、共享封面位置与尺寸、沉浸材质及前景显隐读取同一进度。减少动态效果时仍允许手指逐帧控制，松手和点击即时落定。
- 迷你栏跨路由保留正在处理的指针；回调更新不重启手势。纵向展开区域限定在封面与歌名，保持横向切歌及播放、队列按钮。
- 歌词及队列先处理自身滚动；未消费的下拉交给外壳，外壳接管后允许反向回拖。封面与顶部区域直接下拉。
- 竖屏封面恢复此前的大封面几何规则，移除 0.74 倍紧凑占位及额外下移。保留播放/暂停缩放、小封面模式及横屏规则。
- 迷你栏透明度在绘制层读取，避免每帧重建整个 Chrome 宿主。

经典极简的布局、动画及手势代码保持原样；仅其外层共享宿主增加沉浸分支。未修改播放服务、音源、音频通道、队列业务、歌词舞台、Vulkan 舞台、AOD、主题或底部导航。
