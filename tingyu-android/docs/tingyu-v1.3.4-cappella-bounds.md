# 听屿 Android 1.3.4：群唱背屏气泡边界修复

版本 1.3.4 / versionCode 17，沿用包名和发布签名，可覆盖安装。

## 修复

群唱背屏气泡之前使用整屏宽度计算正文，并将一个占满可读区的行容器放大至 1.07–1.18 倍；左右气泡从不同方向放大，造成右缘出屏、左缘进入摄像头带。

本版只修群唱背屏：

- 正文宽度按右侧可读区计算，计入左右内边距、边框和额外安全间距。
- 背屏行容器保持等比 1，不再将整行向镜头或右边缘放大；逐字出现、气泡宽高展开、淡入淡出保留。
- 按完整句子提前测量高度，仅在超出可用高度时减小字号；不会横向压扁文字，也不通过右侧遮罩裁掉正文。
- 保留自动隐藏的播放控件，不为它额外缩小歌词区。
- 正面群唱仍使用原有放大动画；浮名、花火及共享背屏几何实现未修改。
