# 旧开屏实现注释归档

旧字体轮盘、随机竖条已由品牌 SVG 动画替换；以下保留迁移前的实现注释，仅供追溯。

    /* 浅色底板上白字与白色辉光会看不见，改用浅色主题的墨色。 */

    /* 延迟淡入：命中缓存的秒开不会闪一下遮罩内容。 */

    /* 巨大字号，随视口收缩，窄屏也不会溢出。 */

    /* 每个字母占一个固定宽度的盒子（宽度由脚本按各字体的最大字宽测出来，单位 em，
             跟着 font-size 缩放），字体来回切换时字形变但排版不抖。
             纯白 + text-shadow 辉光，辉光强度由脚本逐字母随机，这里的值是脚本失败时的兜底。 */

    /* 缩放原点压到基线附近，字母大小浮动时底边大致对齐。 */

    /* 循环波形：每根竖条只做 transform 动画，合成器线程执行，不占主线程。 */

    /* --floor / --peak / --alpha / --glow / --w 由下面的内联脚本逐条随机化；
             这里的默认值是脚本失败时的静态兜底。纯白平涂 + 外发光，不做渐变。 */

    /* 不动，但保留随机高度，静态波形仍然有形状。 */

    // 需要透明背景的入口不能盖遮罩：OBS 浏览器源会被直接推流捕获，

    // Electron 的透明播放背景 / 壁纸窗口（main.cjs 传 splash=0）会在桌面上闪一个黑块。

    // 探测失败时保留遮罩，React 挂载后仍会移除它。

    // 波形逐条随机化：高度、宽度、节奏、相位和颜色都带抖动，每次加载的形状都不一样。

    // 同步执行，在首帧绘制前完成；失败时 CSS 里的默认值会兜底成一条静态波形。

    // 中间高、两端低的整体包络，再叠加随机量，形状既像波形又不规整。

    // 白色平涂，只在亮度和辉光半径上留随机：高的条更亮、光晕更散。

    // 随机化失败无所谓，CSS 默认值已经能跑一条波形。

    // Folia 五个字母不断跳到不同字形（Loki 片头那种字体轮盘），偶尔整体落回基准样式。

    // 只用通用字族，再叠加字重、斜体和横向拉伸——不同机器上装的字体不一样，

    // 单靠字体名会退化成同一张脸，加上这几个轴才保证每次跳变都看得出来。

    // 用 canvas 在 100px 基准下量出每个字母在所有候选字形里的最大宽度，换算成 em 写死盒子宽度，

    // 这样字形来回换、词标整体不会左右乱跳。

    // 余量留给最大的缩放组合（1.12 × 1.12），字形放大时不会压到相邻字母。

    // 辉光分三档：干净、微光、过曝。片头里字母亮度参差不齐，靠这个模拟。

    // 遮罩被移除后自己停掉，不留空转的定时器。

    // 一拍只换一个字母，偶尔两个，节奏克制。

    // 大小和宽窄都用 transform 做：不进入布局，盒子宽度不受影响，排版才不会抖。

    // 字体轮盘失败就保持静态词标。

    // Last-resort startup guard: if the module bundle or React root never reaches its first

    // effect, keep the user from staring at an endless loading animation. The splash is replaced

    // with a tappable retry instead of disappearing into an unexplained blank page.
