# S4.2 原生视觉与国际化核查

版本 1.5.63 (278)，2026-11-17；分支 feat/library-search-v2，施工基线 55d02b38。本阶段提交 SHA 见本文件 Git 历史。

资料库、智能歌单编辑与保存、音乐足迹改用统一中英文资源；内置智能规则按 ID 翻译显示名称，用户自定义名称不改写。平台名称继续复用 Omni 本地化解析，不更改 Provider ID、账户或缓存键。搜索来源按钮和歌曲菜单的无障碍标签来自页面协议。

原生歌单卡片将操作按钮移至封面，标题独占封面下方宽度并允许两行。快捷入口和目录网格按可用宽度及系统字体缩放调整列数。歌曲行采用最小高度允许文字撑高，操作触控区保持 48dp。复用现有主题 token、列表、返回栈与底部安全留白；封面菜单使用固定深色底与白色图标保障对比度。没有新增实时效果或动画计时器，没有修改播放器、歌词或底部导航动画。

## 设计差异与范围

继续使用 S1 已有的静态品牌卡片和原生组件。本阶段主要修正资料库与搜索通用布局及文字，不声称逐像素还原设计插画。资料库私人搜索目前仅覆盖已加载资源；远端封面编辑、批量管理、音乐足迹实体导航等缺口仍需补齐。

无数据库迁移。可单独撤销本阶段提交；公共卡片布局影响使用相同组件的目录及资料库页面，需在设备上回归实际长标题与大字体。
