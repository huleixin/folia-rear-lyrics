# 真实收听统计（S2.2）

基线：1.5.63 (278)，分支 feat/library-search-v2，上一阶段 6c931eeb。

复用 PlaybackListenTracker 和 S1 的观察入口，仅播放器正在播放时采样；结算至少 30 秒的有效会话。以会话 ID 主键写入，暂停、缓冲不累计，明显 seek 不累计。小于采样阈值的微小 seek 仍存在与正常进度难以区分的限制。没有从歌曲总时长推算旧记录时长。

IndexedDB 从 v2 非破坏性升级为 v3，仅增加 listening_sessions 表。原收藏、歌单、本地音乐、播放历史和偏好表保留。统计按会话开始时间归属日期/小时；跨午夜会话暂不切分。播放完成率来源于实际有效时长。统计写入失败不影响播放，不按秒写库。

关闭 S1 个性化记录会停止新增统计；清空只影响新增统计表，并重置正在记录的会话，避免清空前时长再次写回。清除失败向调用方报告。

本阶段可计算总有效时长、有效播放次数、不同歌曲/歌手/专辑数、平台占比、每日/小时分布及常听排行。账户过滤先于记录数上限执行；足迹按所选日历范围直接读取，避免近期记录上限遮住较早月份。单次查询最多读取五万条，超出时明确提示；这仍是显式的数据量上限。没有实机音频/性能验收。

验证：智能歌单、统计、迁移和跟踪器共 23/23 测试通过，0 失败；TypeScript 类型检查通过。回退时可停用新增入口及采集器，保留 v3 加表迁移；不可用低版本 Dexie schema 强行降级已升级数据库。

## S4.3 音乐足迹补全（2026-11-17）

版本 1.5.63 (278)，本轮修改基于 16d42bb0。常听歌手和专辑保留原始歌曲、平台和实体标识，通过既有 catalog resolver 打开原生详情。本地只接受可信实体 ID，并沿用本地实体合并重定向；名称不足以确认身份时显示无法打开的提示。关闭足迹、切换账户或页面以及发起新请求都会使迟到的详情结果失效。

统计读取在应用账户过滤后才执行记录数量上限，避免其他账户挤占当前账户额度。足迹按选定日期区间独立查询，仍最多读取五万条，超限明确提示。

当前验证：详情解析、请求生命周期、统计持久化、日期范围、分层约束和 store 合约共 40/40 通过，0 失败，TypeScript 检查通过。没有连接 Android 设备，未完成实际详情交互、音频和性能验收。
