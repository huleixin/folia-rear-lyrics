# S1 实现记录

基线 1.5.62 / 277，分支 feat/discovery-system-v2。原签名证书 SHA-256 实测 a36ef2a5324b55d1b8469bd83b081f43ec9c9ce563f0e6cf67567f8ece02249d。

## 已实现

推荐服务：Omni 新增按 provider 显式读取日推、FM、推荐歌单和历史日推的能力与函数，推荐浏览不切换全局音源。DiscoveryRequestCache 合并同一请求、限制并发为 2、按账户/来源/类型/日期隔离并支持取消；来源循环串行读取，避免首屏同时冲击多个平台。

偏好与雷达：真实媒体进度经 PlaybackListenTracker 结算，同一会话只记一次；时间衰减、每日正向上限、明确负反馈、取消收藏不当作讨厌。心动、风格、探索、时光、本地五类雷达共享候选和偏好，使用稳定日期与换批种子；本地雷达只读本地曲库。小众雷达因缺少可信热度数据不开放。漫游按 50/30/20 组合，可切换偏熟悉/多探索，使用既有队列与播放入口，剩余 4 首内且确实在播放时追加，暂停或页面重建不补充，不重复歌曲，退出恢复原队列。

界面：推荐首页改用原生 Compose 渲染，包含综合/平台筛选、漫游卡、真实日推/FM 快捷入口、三张雷达卡、猜你想听、推荐歌单、最近播放和我的歌单；设置可隐藏/上移模块、调整来源开关与权重、探索程度、熟悉比例、本地纳入、记录开关、清空偏好。历史每日推荐、全部歌单、雷达总览和歌曲菜单复用现有原生面板。详情复用原生集合页，以本地静态快照承载，禁止播放列表编辑动作，不显示平台“重新加载”。平板补充 chips、快捷入口和品牌卡排版。原有本地首页及资料库/搜索路径保留。

## 未完成或受限

相似歌曲/歌单/歌手、全量排行榜、新碟、风格分类、场景分类、小众雷达：当前没有经过验证的统一 provider 合约，未做空壳入口。设计资源中的示意歌曲、数量和热度未使用；未新增独立品牌位图，品牌卡使用主题 token 和轻量渐变。尚未连接真机或模拟器，因此未完成逐帧动画、四主题视觉、长时漫游、帧耗时和真实账号接口验收。基线已有若干单元测试失败，详见 TEST-REPORT，不计入本次通过。
