# 听屿 S2–S4 性能与边界报告

验证日期：2026-11-17
版本：1.5.64（versionCode 279）

## 已审阅的性能保护

- 推荐、资料库和搜索继续复用现有数据层及页面体系；本轮未改 Media3、播放队列、播放器动画、歌词或底部导航动画。
- 听歌足迹按页面打开、日期范围及账户范围读取；既有实现每次最多读取 50,000 条并在超限时显式提示，不用歌曲总时长推算有效时长。
- 搜索来源仍独立管理结果与错误；本地歌手/专辑检索仅使用已就绪目录快照和目录分配，不执行在线请求。
- 未运行设备侧性能采样，故没有可报告的帧耗时、内存峰值、首屏时间、网络请求数或音频稳定性对比值。不得将构建成功解释为性能验收通过。

## 设备验收边界

本轮环境没有可用 Android 真机或模拟器。因此未能录制页面、测量帧时长/内存、验证四套主题和屏幕宽度、离线曲库实际搜索交互，也未完成长时间播放与快速页面切换的设备压力测试。以上均保留为待设备验证项。

## 结论

代码层只记录可由源码和自动化测试支持的结论。设备性能基线及改造前后对比数据缺失，不能据此宣称完成实机性能验收。
