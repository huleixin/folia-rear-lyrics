# 资料库 2.0 实施记录

2026-11-17；版本 1.5.63 (278)，分支 feat/library-search-v2。S2.3 基于 8c1bd2f7，准确提交 SHA 见此文档的 Git 历史。

## 已接入

- 现有原生首页归属内提供综合资料库、单平台歌单/收藏专辑，来源选择独立于全局播放来源。账户水合门控、账户代次隔离、分页、独立失败和重试复用 S2.1 数据层。
- 歌单列表/网格、本地置顶/分组/手动移到最前/名称/歌曲数量/更新时间排序。组织信息不修改源平台数据。
- 私人资料搜索仅查找当前已加载的收藏、历史和本地候选，不混入全网结果；加载范围有明确提示。
- 智能歌单接入真实记录，支持自定义条件、全部/任意匹配、排序/数量限制、预览、保存及删除确认。相同统计窗口共用一次计算。
- 纯本地智能歌单可以另存为普通本地歌单，使用现有创建入口；防止重复提交，失败不提示成功。
- 音乐足迹使用当前账户可见会话，支持今日/本周/本月/本年/全部/自定义日期，真实时长/次数/不同实体数量、常听排行、平台占比、每日及小时条形图。
- 本地资料库现有扫描、导入、分类、编辑、播放入口保留。

## 公共变更及边界

OperationPanel、MobileSheet、MobileScrollFrame 迁至 components/shared，供资料库、搜索和设置复用；更新归属清单，不新增 WebView 正式页面。NativePageModel 兼容增加 bars，Compose 采用静态主题色图形，不引入图表依赖。资料库页面保存最多12个页面键的滚动状态；底部留白同时考虑页面声明和悬浮播放栏实际占位。未修改播放核心、歌词、Melox、迷你播放器及导航动效。

统计读取上限50,000条，用额外一条判断截断；未打开足迹不计算汇总。候选收藏请求受并发、缓存和超时约束，不解析播放 URL。

## 尚未完成 / 验证限制

- 跨平台普通歌单保存、远端创建/封面/描述/批量管理仍需可靠写权限与接口；现有详情操作保留，不能将本地分组当作远端修改。
- 私人搜索尚非全量私人资源索引；歌手/专辑统计项尚未接入实体导航。新统计不补算旧记录有效时长，跨午夜会话归开始日。
- 新增中文文案尚需完整英文适配。无连接设备，四主题、字体缩放、播放与性能仍待实机验证；当前不宣称 S2 全部 P0 已完成。
- 回退本阶段 UI 可撤销相应提交，保留 S2.2 的非破坏性数据库加表迁移，禁止将升级后数据库强制降级。
