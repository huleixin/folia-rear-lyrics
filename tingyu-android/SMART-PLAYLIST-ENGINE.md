# 智能歌单规则层（S2.2）

基线：1.5.63 (278)，分支 feat/library-search-v2，上一阶段 6c931eeb。

复用 SongResult、统一歌曲身份和新增的真实会话记录。规则支持来源、歌手、专辑、名称、收藏、有效次数与时长、最近播放、可信添加时间、音质能力、歌曲时长、文件夹及可信标签；支持全部/任意条件、排序及数量限制。缺失字段不匹配，不推测标签、添加时间或实际播放音质。

预设为 7/30 天常听、很久没听、最近添加、收藏未听、高品质、深夜常听、年度常听。收藏未听仅表示听屿可见记录中未播放。高品质按真实可选音质元数据筛选，不代表最近实际播放的音质。规则保存在现有 Zustand 持久化体系，不创建重复播放历史。

本阶段完成规则与存储基础，原生入口、编辑器、按需候选构建在 S2.3 接入；不能将规则单测通过视为 UI 已验收。

验证：智能歌单、会话统计、数据库迁移、既有收听跟踪器共 4 文件 23 测试通过，0 失败；TypeScript 类型检查通过。无设备视觉验收。
