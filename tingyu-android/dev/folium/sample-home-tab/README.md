# 首页完整页面样例

需要 Folium 1.5。仅使用公开的 `homeTabs`、`openHomeTab`、`commands` 与日志 API，不需要账号、网络或权限。

将本目录中的 `mod.json` 和 `client.mjs` 打成 zip 后，在桌面模组面板安装并启用。这个开发样例不在正式签名模组目录中。

安装并启用后：

1. 在 Grid 或 Bravais 首页选择「首页示例」，或在命令面板运行「打开首页示例」。
2. 检查双栏页面占据完整首页空间，输入文字、换行和 Tab 不触发宿主搜索或导航；Ctrl+K（macOS 为 Cmd+K）可以打开宿主命令面板。Grid 的 Tab / Shift+Tab 也应能从原生页签进入示例页。
3. 点击宿主页头的「返回书库」或原生页签，检查原来页面状态仍在；再次打开可查看内存中的草稿。
4. 点击「移除页面入口」，应卸载页面并返回原生首页；再次运行命令可恢复入口。
5. 禁用模组后入口和命令均消失。查看模组日志中的 `Home demo mounted` 与 `Home demo cleaned up`；离开页面后累计次数应相等。

这个样例只用于人工验证宿主页面能力。草稿没有写入磁盘，重载模组或应用后会清空。切换语言会按新语言重新挂载页面。
