# 搜索系统 2.0 实施记录

基线：aab84c37，feat/library-search-v2；版本 1.5.63 / 278。

## S3.1 统一搜索服务

- 复用 Omni 显式 Provider 查询；综合搜索不切换 activeProviderId 或主页来源。
- 单曲、歌手、专辑、歌单共用最多 3 个并发请求。各来源独立发布结果、错误和游标，已有结果保留展示顺序。
- 快速输入、切换来源、关闭页面取消旧任务；忽略不响应取消的迟到结果。请求等待上限 15 秒。
- 搜索缓存按关键词、来源、实际参与来源和账户访问状态隔离，5 分钟有效，最多 20 个。收藏变动不清空搜索。
- 来源按已配置且具备真实搜索能力的 Provider 动态生成；纯本地主页只开放离线搜索。
- 保留原有本地和 Navidrome 适配、分类分页、历史和播放入口。提取共用账户作用域，保持资料库 API 兼容。

验证：搜索与原生页面模型专项 14 文件 / 76 测试通过；TypeScript typecheck 通过。测试为 mock 数据和模型验证，未验证真实平台响应、Compose 实机视觉和音频稳定性。
