# 听屿 Android 1.1.0 · 第二版

本版按确认的页面清单精简旧界面，并将歌词来源、导入、匹配和单曲时间校准整合为手机操作流程。

## 手机歌词操作

- 从歌词舞台右上角“更多 → 歌词”进入，或从命令面板的歌词工具入口进入。
- 歌曲工具使用“歌曲 / 歌词 / 队列”底部面板；常用操作按钮和控件至少保留 44px 触控高度。
- 在线歌曲可切换平台 / 已导入歌词，本地歌曲保留本地 / 内嵌 / 已匹配歌词；Navidrome 显示当前歌词来源并可重新匹配。
- 保留原歌词读取、导入与解析流程，支持 .fia，歌词导出与批量工具继续由已有命令提供。
- 单曲校准支持 ±0.25 秒步进、毫秒输入与重置；只调整当前歌曲。
- 在线、本地及 Navidrome 匹配弹窗均使用新的单栏界面：原生平台下拉选择、搜索、点选结果、按需展开预览，底部固定“使用这份歌词”。不再显示旧左右双栏。
- 本地歌曲的元数据 / 封面选择、纯音乐标记与 Navidrome 的服务器歌词选项仍在匹配选项中。
- 快速更换歌词平台时，忽略旧搜索返回，避免旧结果覆盖当前平台。

## 清理与保留

- 清理网格、无限墙、TUI、Lattice 拼贴、教程宿主、桌面窗口/远控、OBS 独立入口及模组导出页。
- 原六个播放器面板改由新手机工具承接必要功能；账号登录先迁入 mobile，再移除旧网格目录。
- 原“连接与集成”精简为“音源与系统歌词”，保留 Navidrome 与 Android ColorOS 系统歌词；Shizuku / 背屏入口保留。
- 推荐、移动资料库、搜索、歌单 / 专辑、歌手、歌曲菜单、播放队列、主题、歌词过滤、偏移和开源署名保留。
- Stage API 文档页为清单中的待定项，继续保留。
- 原版舞台全部 14 种模式、6 种背景保留，410 个舞台源码文件逐字节不变。背屏共享的渲染 / 协议代码保留，不能按目录名称误删。
- 推荐背景图、卡片、歌单列表、迷你播放器、Liquid Glass 底栏及八个图标保持首版实现。没有宣称本轮提高舞台帧率。

## 安装、源码与验证

包名 `io.github.huleixin.tingyu`，1.1.0 / versionCode 2；沿用首版发布签名，可更新听屿 1.0.0，仍可与 Folia 并存。minSdk 24 / targetSdk 36。
Release 同时提供签名 APK、对应完整源码、离线页面图册和验证记录。源码快照在附件中，仓库原主分支与 Folia 历史发布保留。
私有签名密钥、密码、本地 SDK 路径和内部回滚备份不包含在发布附件里。Folia 作者、AGPL-3.0 和第三方声明保留。

验证：类型检查、942 项资料库 / 命令单测、30 项歌词 / 数据写回定向单测、30 项原生单测、22 项浏览器回归、Release 构建及 APK 签名校验通过。前两组单测包含少量重叠，不相加作为总数。
浏览器覆盖 320×640、393×852、430×932，歌词文件导入、来源切换、匹配选择、时间校准、切歌、关闭、登录迁移、资料库、图标、安全区和舞台控制。直接验证打包 Web 产物的首页冷启动和设置入口。

本轮未连接 Android 真机或模拟器。安装更新、真实音源播放、后台恢复、厂商系统栏、通知/锁屏和 Shizuku / 背屏仍需实机验收。图册是实际浏览器截图，部分使用测试歌曲；不是 Android 真机截图。
